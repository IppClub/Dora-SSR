# 三个真实 Dora Agent 游戏开发评测

状态：三个真实 Agent 项目的无视觉开发与视觉复查均已完成；G02 有经人工原图核对的修改/复拍，G03 重启与压缩后重分析通过。本地评测已结束，逐项证据见下方各项目 RESULT；这不是所有玩法与输入方式的认证。用户于 2026-09-06 指定本轮先完成本地验证，暂不做真机。

## 方法

三个独立项目均由真正的 Dora Agent 主循环编写和构建，不用研究脚本或本对话代写游戏冒充 Agent 成果。先保留无视觉工具的可运行版本，再在同一会话开放视觉工具执行画面检查、必要修复和复拍。保留原始需求、模型/服务类别、会话/任务 ID、工具步骤、代码前后版本、截图和人工观察。

对每个项目分别检查：构建和启动、实际输入/游戏状态、截图源是否为游戏、视觉读取是否发生、报告准确性、是否根据报告修改、复拍结果是否支持改进。视觉模型的自评不作为唯一通过依据。截图只能证明静态画面，游戏行为单独验证。

# GodotNode Class

**Description:**

&emsp;&emsp;Creates a [GodotNode](/docs/api/Class/GodotNode) from a Godot project directory or exported `.pck` file.

## getUnsupportedReason

```tl
getUnsupportedReason: function(): string
```

Returns an empty string when the current GPU/backend supports GodotNode, or a reason for rejection. Call after Dora initializes its renderer. This checks GPU capabilities only; it does not load or validate the Godot runtime. On iOS, GodotNode requires Apple4 or newer GPU capabilities.

## __call

```tl
metamethod __call: function(self: GodotNodeClass, projectPath: string, sceneFile?: string, width?: integer, height?: integer, buffers?: integer): GodotNode | nil
```

| Parameter | Description |
| --- | --- |
| projectPath | Project directory containing `project.godot`, or an exported `.pck` file; resolved through Dora Content. |
| sceneFile | Godot scene path such as `res://main.tscn`; default empty uses the project main scene. |
| width / height | Output resolution; defaults to 640 × 360, range 1–8192 per dimension. |
| buffers | Output texture buffer count; 2–4, default 3. |

Returns `nil` on immediate validation failure. Otherwise, the node starts asynchronously: check `running` and `lastError`. The Dora package must include a matching Godot runtime. Only one node may be active; when switching projects, wait for the previous node's `unloadAsync` callback to report success.

```lua
local Dora = require("Dora")
local reason = Dora.GodotNode.getUnsupportedReason()
assert(reason == "", reason)
local node = Dora.GodotNode("path/to/project", "", 640, 360, 3)
assert(node)
node:addTo(Dora.Director.ui)
```

# DirectionalLight3D

**Description:**

&emsp;&emsp;A directional light whose direction follows its world rotation.

## color

**Type:** Field.

**Description:**

&emsp;&emsp;The light color in sRGB space.

**Signature:**
```tl
color: Color3
```

## intensity

**Type:** Field.

**Description:**

&emsp;&emsp;The light intensity.

**Signature:**
```tl
intensity: number
```

## castShadow

**Type:** Field.

**Description:**

&emsp;&emsp;Whether this light casts a shadow.

**Signature:**
```tl
castShadow: boolean
```

## shadowBias

**Type:** Field.

**Description:**

&emsp;&emsp;Constant depth bias used by the shadow comparison.

**Signature:**
```tl
shadowBias: number
```

## shadowNormalBias

**Type:** Field.

**Description:**

&emsp;&emsp;Slope-dependent normal bias used by the shadow comparison.

**Signature:**
```tl
shadowNormalBias: number
```

## shadowSoftness

**Type:** Field.

**Description:**

&emsp;&emsp;Shadow filter radius measured in shadow-map texels. Zero disables filtering.

**Signature:**
```tl
shadowSoftness: number
```

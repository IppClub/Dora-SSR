**Description:**

&emsp;&emsp;Represents byte data compressed using a specific algorithm.

## release

**Type:** Function.

**Description:**

&emsp;&emsp;Destroys the object's Lua reference. The object will be completely deleted if it's not referenced by any other
LÖVE object or thread.
This method can be used to immediately clean up resources without waiting for Lua's garbage collector.

**Signature:**
```tl
release: function(self: CompressedData): boolean
```

**Returns:**

| Return Type | Description |
| --- | --- |
| boolean | True if the object was released by this call, false if it had been previously released. |

## getFFIPointer

**Type:** Function.

**Description:**

&emsp;&emsp;Gets an FFI pointer to the Data.
This function should be preferred instead of Data:getPointer because the latter uses light userdata which can't
store more all possible memory addresses on some new ARM64 architectures, when LuaJIT is used.

**Signature:**
```tl
getFFIPointer: function(self: CompressedData): nil
```

**Returns:**

| Return Type | Description |
| --- | --- |
| nil | A raw void* pointer to the Data, or nil if FFI is unavailable. |

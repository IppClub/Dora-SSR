# Material3D

**Description:**

&emsp;&emsp;A per-instance material slot owned by a Model3D instance.

## baseColor

**Type:** Field.

**Description:**

&emsp;&emsp;The base color factor.

**Signature:**
```tl
baseColor: Color
```

## emissive

**Type:** Field.

**Description:**

&emsp;&emsp;The emissive color factor.

**Signature:**
```tl
emissive: Color3
```

## metallic

**Type:** Field.

**Description:**

&emsp;&emsp;The metallic factor.

**Signature:**
```tl
metallic: number
```

## roughness

**Type:** Field.

**Description:**

&emsp;&emsp;The roughness factor.

**Signature:**
```tl
roughness: number
```

## alphaMode

**Type:** Field.

**Description:**

&emsp;&emsp;Alpha mode: 0 opaque, 1 mask, 2 blend.

**Signature:**
```tl
alphaMode: integer
```

## alphaCutoff

**Type:** Field.

**Description:**

&emsp;&emsp;The alpha cutoff used in mask mode.

**Signature:**
```tl
alphaCutoff: number
```

## setBaseColorTexture

**Type:** Function.

**Description:**

&emsp;&emsp;Sets the base color texture.

**Signature:**
```tl
setBaseColorTexture: function(self: Material3D, texture: Texture2D)
```

## clearBaseColorTexture

**Type:** Function.

**Description:**

&emsp;&emsp;Clears the base color texture.

**Signature:**

# Quick Start

## 1. What is Dora SSR?

![Dora SSR overview](@site/static/img/article/detail.svg)

:::info A Short Introduction
Dora SSR is a game engine for rapid development of games on various devices. It has a built-in easy-to-use Web IDE development tool chain that supports direct game development on mobile phones, open source handhelds and other devices.
:::

Install Dora SSR, choose your platform below, and make your first interactive scene. You can also [try games in your browser](https://dora-ssr.net/play).

### 1. Install and launch {#desktop-install}

- **Windows**: install the **Windows x64 MSI**, then launch Dora SSR from the Start menu. Use the package with `-opengl` if your graphics hardware or driver cannot run the default D3D12 version.
- **macOS**: extract the macOS package and open Dora, or install with `brew install --cask ippclub/tap/dora-ssr`.

The **built-in Web IDE opens automatically** in the Dora SSR window. Create your first project below.

<a href={desktopImage} target="_blank" rel="noopener noreferrer" title="Open full-size screenshot">
  <img src={desktopImage} alt="Dora SSR opens its built-in Web IDE on Windows and macOS; shown here on macOS" loading="lazy" style={{height: 'auto'}} />
</a>

Portable ZIP installation and connecting from another device are covered in [Installation](./12.installation.mdx).


### 2. Create a project and add code {#desktop-step-2}

1. In the built-in Web IDE's left resource tree, right-click **Workspace** (or touch and hold), then select **New → Folder**.
2. Enter `Hello`, enable **Create as Project**, keep the default **TypeScript**, and select **OK**.
3. Expand `Hello`, open `init.ts`, and replace its contents with the code below. It displays a logo that moves to where you click or tap.

<a href={createImage} target="_blank" rel="noopener noreferrer" title="Open full-size screenshot">
  <img src={createImage} alt="Create the Hello project: enter its name, enable Create as Project, choose TypeScript, and select OK" loading="lazy" style={{height: 'auto'}} />
</a>

If you prefer another language, select it when creating the project and use the matching example tab.

<TabItem value="ts" label="TypeScript">

```ts title="Hello/init.ts"
import {Ease, Move, Node, Sprite} from 'Dora';
const root = Node();
const sprite = Sprite("Image/logo.png");

if (sprite) {
	root.addChild(sprite);
	root.onTapBegan(touch => {
		sprite.perform(
			Move(
				1, // duration in seconds
				sprite.position, // start position
				touch.location, // end position
				Ease.OutBack // easing function
			)
		);
	});
}
```

<TabItem value="tsx" label="TSX">

```tsx title="Hello/init.tsx"
// @preview-file on
import {React, toNode, toAction, useRef} from 'DoraX';
import {Ease, Sprite, Touch} from 'Dora';

const sprite = useRef<Sprite.Type>();
const onTapBegan = (touch: Touch.Type) => {
	const {current} = sprite;
	if (current) {
		const {x, y} = touch.location;
		current.perform(toAction(
			<move time={1}
				startX={current.x} startY={current.y}
				stopX={x} stopY={y}
				easing={Ease.OutBack}
			/>
		));
	}
};
toNode(
	<node onTapBegan={onTapBegan}>
		<sprite ref={sprite} file='Image/logo.png'/>
	</node>
);
```

<TabItem value="wa" label="Wa">

For Wa, use **New → Wa** and enable **Create as Wa project** to create `Hello`, then edit `src/main.wa`.

```go title="Hello/src/main.wa"
import "dora"

func init {
	sprite := dora.NewSpriteWithFile("Image/logo.png")
	root := dora.NewNode()
	root.AddChild(sprite.Node)
	root.OnTapBegan(func(touch: dora.Touch) {
		sprite.PerformDef(dora.ActionDefMoveTo(
			1.0,                  // Duration, in seconds
			sprite.GetPosition(), // Start position
			touch.GetLocation(),  // End position
			dora.EaseOutBack,     // Easing function
		), false)
	})
}
```

### 3. Run it {#desktop-step-3}

Save with **Ctrl + S**, then click the triangular **Run** button (or press **Ctrl + R**). On macOS, use **⌘** instead of Ctrl.

On **Windows/macOS**, a successful run switches the same Dora SSR window from the built-in IDE to the game. Click or tap to move the logo; select the **IDE** tab on the left to return to editing, then use **Stop** to end the game.

<a href={runImage} target="_blank" rel="noopener noreferrer" title="Open full-size screenshot">
  <img src={runImage} alt="Run Hello from the toolbar, then click or tap in the Dora SSR game window" loading="lazy" style={{height: 'auto'}} />
</a>

### 4. Share your game {#desktop-step-4}

Right-click the `Hello` folder and select **Export → Export HTML**. Extract the entire downloaded ZIP, then open its root `index.html` in a browser to play. Keep all accompanying files. Choose **Export ZIP** instead to back up or share the project for further editing.

Next, learn [how to set up a scene](./30.setup-scene.mdx), explore [other languages](./20.language-select.md), or follow the [first game tutorial](../example/10.First%20Game%20Tutorial/1.start.mdx).

# Installation

Choose your platform below. For a first project, return to [Quick Start](./10.quick-start.mdx).

<Tabs groupId="platform-select">
<TabItem value="android" label="Android">

1. Download and install the APK package on the game's running terminal.

	<Dropdown
		label="Download APK"
		items={[
			{ label: 'GitHub', to: 'https://github.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'Gitee', to: 'https://gitee.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'GitCode', to: 'https://gitcode.com/ippclub/Dora-SSR/releases', target: '_blank' },
	]}/>

2. Launch the app to open the Mobile Feed. Use **Local → + New** to create a project and enter Remix. To write code on a computer instead, select **Classic UI** at the top left of the Feed and open its displayed server address in a browser on the same network.
3. Start game development.

</TabItem>
<TabItem value="windows" label="Windows">

1. Download a Windows **x64** package from the release page. Packages without `-opengl` use **Direct3D 12 (D3D12)**; choose a package with `-opengl` if your graphics hardware or driver cannot run the D3D12 version.

	<Dropdown
		label="Download Software"
		items={[
			{ label: 'GitHub', to: 'https://github.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'Gitee', to: 'https://gitee.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'GitCode', to: 'https://gitcode.com/ippclub/Dora-SSR/releases', target: '_blank' },
	]}/>

2. Choose one installation method:
   - **MSI installer** (`windows-x64.msi` or `windows-x64-opengl.msi`): run the installer, then launch **Dora SSR** from the Start menu. The default installation directory is `%LOCALAPPDATA%\Programs\Dora SSR`.
   - **Portable ZIP** (`windows-x64.zip` or `windows-x64-opengl.zip`): extract the entire archive into a writable folder, then run `Dora.exe`. Keep the bundled DLLs and resource folders together with the executable.
3. Dora SSR automatically opens its built-in Web IDE. Create and edit projects directly in the application window.
4. Start game development.

The MSI installer registers `dora-ssr://` links for the current user. For the portable ZIP, run `RegisterDoraLinks.cmd` beside `Dora.exe` if you want to open those links from a browser. Register again after moving the extracted folder.

</TabItem>
<TabItem value="macos" label="macOS">

1. Download and run the software.

	<Dropdown
		label="Download Software"
		items={[
			{ label: 'GitHub', to: 'https://github.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'Gitee', to: 'https://gitee.com/ippclub/Dora-SSR/releases/latest', target: '_blank' },
			{ label: 'GitCode', to: 'https://gitcode.com/ippclub/Dora-SSR/releases', target: '_blank' },

	]}/>

	Or you can install with [Homebrew](https://brew.sh) using:
	```sh
	brew install --cask ippclub/tap/dora-ssr
	```
	Subsequent updates can be performed using the following commands:
	```sh
	brew update
	brew upgrade dora-ssr
	# or try to update the revision of the same version by reinstalling
	brew reinstall dora-ssr
	```

	When you first run the software, you may see a prompt saying "Dora cannot be opened". Please go to "System Preferences" > "Security & Privacy" and click "Open Anyway".

2. Dora SSR automatically opens its built-in Web IDE. Create and edit projects directly in the application window.
3. Start game development.

</TabItem>
<TabItem value="linux" label="Linux">

1. Installation.
	- Ubuntu
		```sh
		sudo add-apt-repository ppa:ippclub/dora-ssr
		sudo apt update
		sudo apt install dora-ssr
		```
	- Debian Bookworm
		```sh
		sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 9C7705BF
		sudo add-apt-repository -S "deb https://ppa.launchpadcontent.net/ippclub/dora-ssr/ubuntu jammy main"
		sudo apt update
		sudo apt install dora-ssr
		```
2. Run the software and access the server address displayed by the software through a browser.
3. Start game development.

</TabItem>

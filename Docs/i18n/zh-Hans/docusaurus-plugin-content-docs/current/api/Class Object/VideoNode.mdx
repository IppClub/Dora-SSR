# VideoNode的类对象

**描述：**

&emsp;&emsp;用于创建 VideoNode 实例的类。

## __call

**类型：** 元方法。

**描述：**

&emsp;&emsp;构造函数，用于创建一个 VideoNode 实例。

**签名：**
```tl
metamethod __call: function(
		self: VideoNodeClass,
		filename: string,
		looped?: boolean --[[false]]
	): VideoNode | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| filename | string | 视频文件路径，应为包含 Theora 视频流的 Ogg（`.ogv`）文件。VideoNode 通过 Dora Content 读取，仅渲染视频，支持 Theora 4:2:0/4:2:2/4:4:4 并使用软件解码；音频需单独播放。 |
| looped | boolean | [可选] 是否循环播放，默认为 false。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| VideoNode \| nil | 新创建的 VideoNode 实例。如果创建失败，则返回 nil。 |

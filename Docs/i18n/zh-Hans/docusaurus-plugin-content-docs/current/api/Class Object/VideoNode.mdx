# VideoNode的类对象

**描述：**

&emsp;&emsp;用于创建 VideoNode 实例的类。

Web 版的 dora-preset 默认支持 Ogg/Theora 视频及内嵌 Vorbis 音轨；core 配置需要启用 VIDEO。视频解码在主循环执行，不要求 pthreads 或 SharedArrayBuffer。音频播放需要满足浏览器的用户操作解锁规则。

## __call

**类型：** 元方法。

**描述：**

&emsp;&emsp;构造函数，用于创建一个 VideoNode 实例。

**签名：**
```tl
metamethod __call: function(
		self: VideoNodeClass,
		filename: string,
		looped?: boolean --[[false]]
	): VideoNode | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| filename | string | 视频文件路径，应为包含 Theora 视频流的 Ogg（`.ogv`）文件。VideoNode 通过 Dora Content 读取，支持 Theora 4:2:0/4:2:2/4:4:4 软件解码，并自动播放内嵌 Vorbis 音轨；暂停、恢复和循环播放会同步控制音画。 |
| looped | boolean | [可选] 是否循环播放，默认为 false。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| VideoNode \| nil | 新创建的 VideoNode 实例。如果创建失败，则返回 nil。 |

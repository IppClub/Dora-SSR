# LoveNode的类对象

**描述：**

&emsp;&emsp;用于创建 LoveNode 对象的类。

## __call

**类型：** 元方法。

**描述：**

&emsp;&emsp;使用启动 Lua 文件、`.love` 包或 ZIP 包创建 LoveNode。不带扩展名的相对路径也会解析到对应的 `.love`、`.zip` 或 `main.lua` 项目入口。

**签名：**
```tl
metamethod __call: function(self: LoveNodeClass, bootFile: string): LoveNode | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| bootFile | string | 启动 Lua 文件、`.love` 包、ZIP 包或不带扩展名的 Love 项目在 Dora Content 中的路径。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| LoveNode \| nil | 创建的 LoveNode；项目无法加载时返回 nil。 |

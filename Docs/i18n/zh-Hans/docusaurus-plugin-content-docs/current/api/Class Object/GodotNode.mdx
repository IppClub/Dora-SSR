# GodotNode 类

**描述：**

&emsp;&emsp;从 Godot 项目目录或导出的 `.pck` 文件创建 [GodotNode](/docs/api/Class/GodotNode)。

## getUnsupportedReason

```tl
getUnsupportedReason: function(): string
```

当前 GPU／后端支持 GodotNode 时返回空字符串，否则返回拒绝原因。应在 Dora 初始化渲染器后调用。此方法仅检查 GPU 能力，不会加载或验证 Godot 运行库。iOS 上 GodotNode 要求 Apple4 或更新的 GPU 能力。

## __call

```tl
metamethod __call: function(self: GodotNodeClass, projectPath: string, sceneFile?: string, width?: integer, height?: integer, buffers?: integer): GodotNode | nil
```

| 参数 | 描述 |
| --- | --- |
| projectPath | 包含 `project.godot` 的项目目录或导出的 `.pck` 文件，通过 Dora Content 解析。 |
| sceneFile | Godot 场景路径，例如 `res://main.tscn`；默认空字符串表示项目主场景。 |
| width / height | 输出分辨率，默认 640 × 360，每个维度范围为 1–8192。 |
| buffers | 输出纹理缓冲数量，范围 2–4，默认 3。 |

即时验证失败返回 `nil`，否则返回异步启动的节点，请检查 `running` 和 `lastError`。Dora 运行包须包含匹配的 Godot 运行库。同一时间仅允许一个活动节点；切换项目前，须等待旧节点的 `unloadAsync` 回调报告成功。

```lua
local Dora = require("Dora")
local reason = Dora.GodotNode.getUnsupportedReason()
assert(reason == "", reason)
local node = Dora.GodotNode("path/to/project", "", 640, 360, 3)
assert(node)
node:addTo(Dora.Director.ui)
```

## checkCodeAsync

```tl
checkCodeAsync: function(self: GodotNodeClass, project: string, file: string, content: string, callback: function(available: boolean, result: string))
```

通过内置 runtime 检查未保存的 GDScript、文本场景／资源、shader／include 或 `project.godot`。项目和文件须使用绝对路径。Metal、GL／GLES／WebGL、D3D12 共用同一检查器。不执行场景、Autoload 或用户脚本，也不导入素材或编译后端 GPU 管线。

回调在 Dora 逻辑线程执行。`available` 为假时，`result` 为能力／错误消息；否则为含 `success` 与 `info` 诊断的 JSON 字符串。旧 runtime 缺少扩展时返回能力错误。

## importAssetAsync

```tl
importAssetAsync: function(self: GodotNodeClass, project: string, file: string, options: string, callback: function(available: boolean, result: string))
```

在 macOS、Windows 或 Linux 桌面版中直接使用内置 runtime 导入单个素材。项目和文件须使用绝对路径，`options` 为 JSON 字符串（`{}` 或 `{"force":true}`）。先停止正在运行的 Godot 工程。支持图片、WAV／MP3／Ogg Vorbis 音频、字体和 glTF／GLB 的默认导入。已有编辑器管理的导入设置会保留，并返回失败而不覆盖。

逻辑线程回调的 `available` 含义同 `checkCodeAsync`。JSON 响应包含 `success`、`status`（`imported`／`skipped`／`failed`）、`path`、`output` 和 `message`。产物写入 `.godot/imported`，并生成素材旁的 `.import` 映射及 UID 缓存，不修改原素材。源文件与产物校验和用于识别失效或损坏的缓存；模型始终重新导入以包含外部 buffer／纹理。不启动外部 Godot 可执行程序、场景、Autoload 或用户脚本。Agent 应使用 `execute_command` 的 Lua 注入函数 `importGodotAssets({project=".", paths={"art/player.png"}})` 解析工作区路径并取得批量结果。

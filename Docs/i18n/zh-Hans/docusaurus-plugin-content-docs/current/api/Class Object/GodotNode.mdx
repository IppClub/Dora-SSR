# GodotNode 类

**描述：**

&emsp;&emsp;从 Godot 项目目录或导出的 `.pck` 文件创建 [GodotNode](/docs/api/Class/GodotNode)。

## getUnsupportedReason

```tl
getUnsupportedReason: function(): string
```

当前 GPU／后端支持 GodotNode 时返回空字符串，否则返回拒绝原因。应在 Dora 初始化渲染器后调用。此方法仅检查 GPU 能力，不会加载或验证 Godot 运行库。iOS 上 GodotNode 要求 Apple4 或更新的 GPU 能力。

## __call

```tl
metamethod __call: function(self: GodotNodeClass, projectPath: string, sceneFile?: string, width?: integer, height?: integer, buffers?: integer): GodotNode | nil
```

| 参数 | 描述 |
| --- | --- |
| projectPath | 包含 `project.godot` 的项目目录或导出的 `.pck` 文件，通过 Dora Content 解析。 |
| sceneFile | Godot 场景路径，例如 `res://main.tscn`；默认空字符串表示项目主场景。 |
| width / height | 输出分辨率，默认 640 × 360，每个维度范围为 1–8192。 |
| buffers | 输出纹理缓冲数量，范围 2–4，默认 3。 |

即时验证失败返回 `nil`，否则返回异步启动的节点，请检查 `running` 和 `lastError`。Dora 运行包须包含匹配的 Godot 运行库。同一时间仅允许一个活动节点；切换项目前，须等待旧节点的 `unloadAsync` 回调报告成功。

```lua
local Dora = require("Dora")
local reason = Dora.GodotNode.getUnsupportedReason()
assert(reason == "", reason)
local node = Dora.GodotNode("path/to/project", "", 640, 360, 3)
assert(node)
node:addTo(Dora.Director.ui)
```

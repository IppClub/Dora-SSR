# LoveNode

**描述：**

&emsp;&emsp;Dora 场景节点，每个实例拥有并运行一个隔离的 Love Lua State。

**类对象：**[LoveNode Class](/docs/api/Class%20Object/LoveNode)。

## bootFile

**类型：** 成员变量。

**描述：**

&emsp;&emsp;创建该 LoveNode 时使用的启动文件或项目包路径。

**签名：**
```tl
bootFile: string
```

## sourceRoot

**类型：** 成员变量。

**描述：**

&emsp;&emsp;解析该 LoveNode 项目文件时使用的根目录。

**签名：**
```tl
sourceRoot: string
```

## lastError

**类型：** 成员变量。

**描述：**

&emsp;&emsp;加载或运行 Love 项目时最近一次报告的错误；空字符串表示尚未报告错误。

**签名：**
```tl
lastError: string
```

## running

**类型：** 成员变量。

**描述：**

&emsp;&emsp;该 LoveNode 当前是否持有正在运行的 Love Lua State。

**签名：**
```tl
running: boolean
```

## restart

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁旧 Love State，重新读取 boot 文件，并启动一个全新 State。

**签名：**
```tl
restart: function(self: LoveNode): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | Love 项目是否成功重新启动。 |

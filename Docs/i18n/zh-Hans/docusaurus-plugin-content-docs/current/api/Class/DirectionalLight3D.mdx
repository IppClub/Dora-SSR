# DirectionalLight3D

**描述：**

&emsp;&emsp;方向由世界旋转决定的方向光。

## color

**类型：** 成员变量。

**描述：**

&emsp;&emsp;sRGB 空间中的灯光颜色。

**签名：**
```tl
color: Color3
```

## intensity

**类型：** 成员变量。

**描述：**

&emsp;&emsp;灯光强度。

**签名：**
```tl
intensity: number
```

## castShadow

**类型：** 成员变量。

**描述：**

&emsp;&emsp;是否让该方向光投射阴影。

**签名：**
```tl
castShadow: boolean
```

## shadowBias

**类型：** 成员变量。

**描述：**

&emsp;&emsp;阴影深度比较使用的固定偏移。

**签名：**
```tl
shadowBias: number
```

## shadowNormalBias

**类型：** 成员变量。

**描述：**

&emsp;&emsp;阴影深度比较使用的斜率相关法线偏移。

**签名：**
```tl
shadowNormalBias: number
```

## shadowSoftness

**类型：** 成员变量。

**描述：**

&emsp;&emsp;以阴影贴图 texel 为单位的阴影过滤半径。设为零会关闭过滤。

**签名：**
```tl
shadowSoftness: number
```

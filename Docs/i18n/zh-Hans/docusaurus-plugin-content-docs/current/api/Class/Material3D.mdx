# Material3D

**描述：**

&emsp;&emsp;由 Model3D 实例持有的逐实例材质槽。

## baseColor

**类型：** 成员变量。

**描述：**

&emsp;&emsp;基础颜色系数。

**签名：**
```tl
baseColor: Color
```

## emissive

**类型：** 成员变量。

**描述：**

&emsp;&emsp;自发光颜色系数。

**签名：**
```tl
emissive: Color3
```

## metallic

**类型：** 成员变量。

**描述：**

&emsp;&emsp;金属度系数。

**签名：**
```tl
metallic: number
```

## roughness

**类型：** 成员变量。

**描述：**

&emsp;&emsp;粗糙度系数。

**签名：**
```tl
roughness: number
```

## alphaMode

**类型：** 成员变量。

**描述：**

&emsp;&emsp;透明模式：0 不透明，1 遮罩，2 混合。

**签名：**
```tl
alphaMode: integer
```

## alphaCutoff

**类型：** 成员变量。

**描述：**

&emsp;&emsp;遮罩模式使用的透明度阈值。

**签名：**
```tl
alphaCutoff: number
```

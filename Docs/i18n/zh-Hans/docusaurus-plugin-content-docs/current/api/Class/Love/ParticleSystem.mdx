# ParticleSystem

**描述：**

&emsp;&emsp;粒子系统可用于创建粒子效果，例如火焰或烟雾。

## type

**类型：** 函数。

**描述：**

&emsp;&emsp;获取字符串形式的对象类型。

**签名：**
```tl
type: function(self: ParticleSystem): string
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string | 字符串类型。 |

## Of

**类型：** 函数。

**描述：**

&emsp;&emsp;检查对象是否属于某种类型。如果对象的层次结构中具有指定名称的类型，则此函数将返回 true。

**签名：**
```tl
typeOf: function(self: ParticleSystem, type_name: string): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| type_name | string | 要检查的类型的名称。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象属于指定类型，则为 true，否则为 false。 |

## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: ParticleSystem): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## clone

**类型：** 函数。

**描述：**

&emsp;&emsp;创建处于停止状态的粒子系统的相同副本。
重载说明：
1. 克隆的粒子系统继承原始粒子系统的所有可设置状态，但它们被初始化为停止状态。

**签名：**
```tl
clone: function(self: ParticleSystem): ParticleSystem
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| ParticleSystem | 此粒子系统的新的相同副本。 |

## setEmissionArea

**类型：** 函数。

**描述：**

&emsp;&emsp;设置粒子的基于区域的生成参数。新创建的粒子将根据此函数的参数在发射器周围的区域中生成。

**签名：**
```tl
setEmissionArea: function(self: ParticleSystem, distribution?: ParticleAreaSpreadDistribution, x?: number, y?: number, angle?: number, relative?: boolean)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| distribution | ParticleAreaSpreadDistribution | 新粒子的分布类型。 |
| x | number | 均匀分布时沿 x 轴距发射器的最大生成距离，或正态分布时沿 x 轴的标准偏差。 |
| y | number | 均匀分布时沿 y 轴距发射器的最大生成距离，或正态分布时沿 y 轴的标准偏差。 |
| angle | number | 发射区域的角度（以弧度表示）。 （默认值：0。） |
| relative | boolean | 如果新生成的粒子将相对于发射区域的中心定向，则为 true，否则为 false。 （默认值：假。） |

# Timer

**描述：**

&emsp;&emsp;提供用户时钟的接口。

## step

**类型：** 函数。

**描述：**

&emsp;&emsp;测量两帧之间的时间。
调用此函数会更改 love.timer.getDelta.

**签名：**
```tl
step: function(): number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 过去的时间（以秒为单位）。 |

## getDelta

**类型：** 函数。

**描述：**

&emsp;&emsp;返回最后两帧之间的时间。

**签名：**
```tl
getDelta: function(): number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 过去的时间（以秒为单位）。 |

## getFPS

**类型：** 函数。

**描述：**

&emsp;&emsp;返回当前每秒帧数。

**签名：**
```tl
getFPS: function(): integer
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| integer | 当前的 FPS。 |

## getAverageDelta

**类型：** 函数。

**描述：**

&emsp;&emsp;返回最后一秒的平均增量时间（每帧秒数）。

**签名：**
```tl
getAverageDelta: function(): number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 最后一秒的平均增量时间。 |

## sleep

**类型：** 函数。

**描述：**

&emsp;&emsp;将当前线程暂停指定的时间。

**签名：**
```tl
sleep: function(seconds: number)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| seconds | number | 还需要睡觉几秒。 |

## getTime

**类型：** 函数。

**描述：**

&emsp;&emsp;返回未指定起始时间的计时器的值。
该函数只能用于计算时间点之间的差异，因为计时器的启动时间未知。

**签名：**
```tl
getTime: function(): number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 时间以秒为单位。以十进制形式给出，精确到微秒。 |

# Audio

**描述：**

&emsp;&emsp;提供一个用用户扬声器产生噪音的接口。

## newSource

**类型：** 函数。

**描述：**

&emsp;&emsp;从文件路径、文件、解码器或声音数据创建新的源。

	-- 从 SoundData 创建的源始终是静态的。

**签名：**
```tl
newSource: function(filename: string, source_type?: string): Source
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| filename | string | 音频文件的文件路径。 |
| source_type | string | 流式或静态源。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Source | source — 可以播放指定音频的新源。 |

## newQueueableSource

**类型：** 函数。

**描述：**

&emsp;&emsp;创建一个新的源，可用于使用 Source:queue 实时生成的声音播放。
重载说明：
1. 与 Source:queue 一起使用的任何 SoundData 的采样率、位深度和通道数必须与提供给此构造函数的参数相匹配。

**签名：**
```tl
newQueueableSource: function(sample_rate: integer, bit_depth: integer, channels: integer, buffers?: integer): Source
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| sample_rate | integer | 播放时每秒的采样数。 |
| bit_depth | integer | 每个样本的位数（8 或 16）。 |
| channels | integer | 1 用于单声道或 2 用于立体声。 |
| buffers | integer | 在任何给定时间可以使用 Source:queue 排队的缓冲区数量。不能大于 64。如果未指定值，则选择合理的默认值 (~8)。 （默认值：0。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Source | 可与 Source:queue 一起使用的新源。 |

## setEffect

**类型：** 函数。

**描述：**

&emsp;&emsp;定义可以应用于源的效果。
并非所有系统都支持音频效果。使用love.audio.isEffectsSupported进行检查。

**签名：**
```tl
setEffect: function(name: string, settings?: AudioEffectSettings | boolean): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| name | string | 效果的名称。 |
| settings | AudioEffectSettings or boolean | 用于此效果的设置，具有以下字段： type: 要使用的效果类型。 volume: 效果的音量。 ...: 特定于效果的设置。请参阅 EffectType 了解可用效果及其相应的设置。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 效果是否创建成功。取决于过载：效果是否成功禁用。 |

## getRecordingDevices

**类型：** 函数。

**描述：**

&emsp;&emsp;获取系统上的 RecordingDevices 列表。
列表中的第一个设备是用户的默认录音设备。如果没有麦克风连接到系统，则该列表可能为空。
iOS 目前不支持录音。
重载说明：
1. Android从11.3开始支持录音。但是，使用 Play Store 中的 APK 时不支持。

**签名：**
```tl
getRecordingDevices: function(): {RecordingDevice}
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| \{RecordingDevice} | 连接的录音设备列表。 |

**返回值：**

| 返回类型 | 描述 |

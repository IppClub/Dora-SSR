# Physics

**描述：**

&emsp;&emsp;可以真实地模拟二维刚体物理。该模块基于Box2D，并且该API与Box2D API尽可能接近地对应。

## setMeter

**类型：** 函数。

**描述：**

&emsp;&emsp;将像素设置为米比例因子。
物理模块中的所有坐标都除以该数字并转换为米，它创建了一种将对象直接绘制到屏幕上而不需要图形转换的便捷方法。
建议创建不大于10倍比例的形状。这很重要，因为 Box2D 经过调整，可以很好地处理 0.1 到 10 米的形状尺寸。默认仪表刻度为 30。

**签名：**
```tl
setMeter: function(scale: number)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| scale | number | 整数比例因子。 |

## newBody

**类型：** 函数。

**描述：**

&emsp;&emsp;创建一个新的实体。
身体分为三种类型。
* 静态物体不移动，具有无限质量，可用于关卡边界。
* 动态物体是模拟中的主要角色，它们与一切物体发生碰撞。
* 运动体不会对力产生反应，只会与动态体发生碰撞。
连接或移除夹具时会计算主体的质量，但可以随时使用 Body:setMass 或 Body:resetMassData 进行更改。

**签名：**
```tl
newBody: function(world: World, x?: number, y?: number, body_type?: string): Body
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| world | World | 创造身体的世界。 |
| x | number | 主体的 x 位置。 （默认值：0。） |
| y | number | 主体的 y 位置。 （默认值：0。） |
| body_type | string | 主体的类型。 （默认：'static'。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Body | 一个新的身体。 |

## newDistanceJoint

**类型：** 函数。

**描述：**

&emsp;&emsp;在两个实体之间创建一个 DistanceJoint。
该关节将两个物体上两点之间的距离限制为恒定。这两个点是在世界坐标中指定的，并且在创建此关节时假定两个主体就位。第一个锚点连接到第一主体，第二个锚点连接到第二主体，并且这些点限定距离关节的长度。

**签名：**
```tl
newDistanceJoint: function(body1: Body, body2: Body, x1: number, y1: number, x2: number, y2: number, collide_connected?: boolean): Joint
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| body1 | Body | 第一个连接到关节的主体。 |
| body2 | Body | 连接到关节的第二个主体。 |
| x1 | number | 第一个锚点（世界空间）的 x 位置。 |
| y1 | number | 第一个锚点（世界空间）的 y 位置。 |
| x2 | number | 第二个锚点（世界空间）的 x 位置。 |
| y2 | number | 第二个锚点（世界空间）的 y 位置。 |
| collide_connected | boolean | 指定两个实体是否应该相互碰撞。 （默认值：假。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Joint | 新的距离关节。 |

## newGearJoint

**类型：** 函数。

**描述：**

&emsp;&emsp;创建连接两个关节的 GearJoint。
齿轮接头连接两个必须是棱柱或旋转接头的接头。使用这个关节需要它使用的关节将各自的身体连接到地面，并以地面作为第一身体。破坏主体和关节时，必须确保先破坏齿轮关节，然后再破坏其他关节。
齿轮接头具有一个比率，该比率确定所连接接头的角度或距离值如何相互关联。公式坐标 1 + 比率 * 坐标 2 始终具有在创建齿轮接头时设置的常量值。

**签名：**
```tl

```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| joint1 | Joint | 第一个与齿轮接头连接的接头。 |
| joint2 | Joint | 与齿轮接头连接的第二个接头。 |
| ratio | number | 齿轮比。 （默认值：1。） |
| collide_connected | boolean | 指定两个实体是否应该相互碰撞。 （默认值：假。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Joint | 新的齿轮接头。 |

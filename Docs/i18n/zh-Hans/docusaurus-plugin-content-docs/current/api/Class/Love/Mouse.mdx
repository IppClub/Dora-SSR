## isDown

**类型：** 函数。

**描述：**

&emsp;&emsp;检查某个鼠标按钮是否按下。

	-- 该函数不检测鼠标滚轮滚动；您必须使用 love.wheelmoved （或 0.9.2 及更早版本中的 love.mousepressed ）回调。

**签名：**
```tl
isDown: function(buttons: number...): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| buttons | number... | 要检查的按钮的索引。 1 是鼠标主按钮，2 是鼠标辅助按钮，3 是中间按钮。其他按钮取决于鼠标。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | down — 如果任何指定的按钮被按下，则为真。 |

## setRelativeMode

**类型：** 函数。

**描述：**

&emsp;&emsp;设置鼠标是否启用相对模式。
当启用相对模式时，光标被隐藏，并且在鼠标移动时不会移动，但仍然通过 love.mousemoved. 生成相对鼠标运动事件，这使得鼠标可以无限期地向任何方向移动，而光标不会卡在屏幕边缘。
在启用相对模式时，即使生成了相对鼠标运动事件，报告的鼠标位置也可能不会更新。

**签名：**
```tl
setRelativeMode: function(relative: boolean): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| relative | boolean | true 则启用相对模式， false 则禁用它。 |

在启用相对模式时，即使生成了相对鼠标运动事件，报告的鼠标位置也不会更新。

## newCursor

**类型：** 函数。

**描述：**

&emsp;&emsp;从图像文件或 ImageData 创建新的硬件 Cursor 对象。
硬件光标与帧速率无关，并且与普通操作系统光标的工作方式相同。与在鼠标的当前坐标处绘制图像不同，即使在低帧速率下，硬件光标在鼠标移动和光标位置更新之间也不会出现明显的滞后。
热点是操作系统用来确定单击的内容以及鼠标光标所在位置的点。例如，普通箭头指针通常将其热点放在图像的左上角，但十字光标可能将其放在中间。

**签名：**
```tl
newCursor: function(image: ImageData | FileData | string, hot_x?: integer, hot_y?: integer): Cursor
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| image | ImageData or FileData or string | 用于新 Cursor 的 ImageData。根据重载：用于新光标的图像路径。取决于重载：表示用于新光标的图像的数据。 |
| hot_x | integer | 光标热点的 ImageData 中的 x 坐标。 （默认值：0。）取决于重载：光标热点图像中的 x 坐标。 （默认值：0。） |
| hot_y | integer | 光标热点的 ImageData 中的 y 坐标。 （默认值：0。）取决于过载：光标热点图像中的 y 坐标。 （默认值：0。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Cursor | 新的 Cursor 对象。 |

## getSystemCursor

**类型：** 函数。

**描述：**

&emsp;&emsp;获取表示系统本机硬件光标的 Cursor 对象。
硬件光标与帧速率无关，并且与普通操作系统光标的工作方式相同。与在鼠标的当前坐标处绘制图像不同，即使在低帧速率下，硬件光标在鼠标移动和光标位置更新之间也不会出现明显的滞后。
重载说明：
1. 'image' CursorType 不是有效参数。使用 love.mouse.newCursor 使用自定义图像创建硬件光标。

**签名：**
```tl
getSystemCursor: function(cursor_type: SystemCursor): Cursor
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| cursor_type | SystemCursor | 要获取的系统光标的类型。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| Cursor | 表示系统游标类型的 Cursor 对象。 |

# Mesh

**描述：**

&emsp;&emsp;用于绘制任意纹理形状的 2D 多边形网格。

## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: Mesh): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## setVertices

**类型：** 函数。

**描述：**

&emsp;&emsp;用新顶点替换网格中的一系列顶点。网格体的顶点总数在创建后就无法更改。这通常比在循环中调用 Mesh:setVertex 更有效。

**签名：**
```tl
setVertices: function(self: Mesh, vertices: {MeshVertex}, start_vertex?: integer, vertex_count?: integer)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| vertices | \{MeshVertex} | 该表填充了每个顶点的顶点信息表，其形式为\{vertex, ...}，其中每个顶点是一个形式为\{attributecomponent, ...}的表。 |
| start_vertex | integer | 要替换的第一个顶点的索引。 （默认值：1。） |
| vertex_count | integer | 要替换的顶点数量。 （默认值：全部。） |

## getVertex

1. 返回值的顺序与网格顶点格式中顶点属性的顺序相同。不是使用自定义顶点格式创建的标准网格将返回两个位置号、两个纹理坐标

2. 获取不是使用自定义顶点格式创建的网格的顶点组件。

**签名：**
```tl

```

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| index | integer | 要检索其信息的顶点的从一开始的索引。取决于过载：要检索其信息的顶点的索引。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| any | 指定顶点中第一个顶点属性的第一个组件。 |

## setAttributeEnabled

**类型：** 函数。

**描述：**

&emsp;&emsp;启用或禁用网格中的特定顶点属性。绘制网格时不使用禁用属性中的顶点数据。

**签名：**
```tl
setAttributeEnabled: function(self: Mesh, name: string, enabled: boolean)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| name | string | 要启用或禁用的顶点属性的名称。 |
| enabled | boolean | 绘制此Mesh时是否使用顶点属性。 |

## attachAttribute

**类型：** 函数。

**描述：**

&emsp;&emsp;将来自不同网格的顶点属性附加到此网格上，以供绘制时使用。这可用于在多个不同网格之间共享顶点属性数据。
重载说明：
1. 如果网格不是使用自定义顶点格式创建的，它将具有 3 个顶点属性，分别名为 VertexPosition、VertexTexCoord 和 VertexColor。可以通过将自定义命名属性声明为属性 vec4
MyCustomAttributeName 在顶点着色器中访问它们；位于顶点着色器代码的顶层。该名称必须与网格体顶点格式和 Mesh:attachAttribute 的名称参数中指定的名称相匹配。

**签名：**
```tl
attachAttribute: function(self: Mesh, name: string, mesh: Mesh, step?: string, attribute_name?: string)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| name | string | 要附加的顶点属性的名称。 |
| mesh | Mesh | 要从中获取顶点属性的网格体。 |
| step | string | 绘制网格时该属性是按顶点还是按实例。 （默认：'pervertex'。） |
| attribute_name | string | 在着色器代码中使用的属性的名称。默认为给定网格中的属性名称。可用于在渲染时为此属性使用不同的名称。 （默认值：名称。） |

## flush

**类型：** 函数。

**描述：**

&emsp;&emsp;立即将Mesh中所有修改的顶点数据发送到显卡。
通常不需要调用此方法，因为 love.graphics.draw(mesh, ...) 会在需要时自动执行此操作，但显式使用 **Mesh:flush** 可以更好地控制工作何时发生。
如果使用此方法，则通常不应在 love.graphics.draw(mesh, ...) 调用之间多次（最多）调用它。

**签名：**
```tl
flush: function(self: Mesh)
```

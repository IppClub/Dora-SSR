# File

**描述：**

&emsp;&emsp;表示文件系统上的一个文件。接受文件路径的函数也可以接受文件。

## type

**类型：** 函数。

**描述：**

&emsp;&emsp;获取字符串形式的对象类型。

**签名：**
```tl
type: function(self: File): string
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string | 字符串类型。 |

## Of

**类型：** 函数。

**描述：**

&emsp;&emsp;检查对象是否属于某种类型。如果对象的层次结构中具有指定名称的类型，则此函数将返回 true。

**签名：**
```tl
typeOf: function(self: File, type_name: string): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| type_name | string | 要检查的类型的名称。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象属于指定类型，则为 true，否则为 false。 |

## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: File): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## open

**类型：** 函数。

**描述：**

&emsp;&emsp;打开文件进行写入、读取或追加。
重载说明：
1. 如果您收到错误消息'Could not set write directory'，请尝试设置保存目录。这可以通过 love.filesystem.setIdentity 或通过在 love.conf
中设置身份字段来完成（仅适用于 love 0.7 或更高版本）。

**签名：**
```tl
open: function(self: File, mode: FileMode): boolean | nil, string | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| mode | FileMode | 打开文件的模式。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean or nil | 成功则为 true，否则为 false。 |
| string or nil | 发生错误时的错误字符串。 |

## setBuffer

**类型：** 函数。

**描述：**

&emsp;&emsp;设置为写入或追加而打开的文件的缓冲模式。启用缓冲的文件在达到缓冲区大小限制之前不会将数据写入磁盘，具体取决于缓冲模式。
File:flush 将强制将所有缓冲数据写入磁盘。

**签名：**
```tl
setBuffer: function(self: File, mode: BufferMode, size?: integer): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| mode | BufferMode | 要使用的缓冲模式。 |
| size | integer | 文件缓冲区的最大大小（以字节为单位）。 （默认值：0。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 缓冲模式是否设置成功。 |

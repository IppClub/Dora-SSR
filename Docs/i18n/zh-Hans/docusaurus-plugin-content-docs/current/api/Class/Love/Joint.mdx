# Joint

**描述：**

&emsp;&emsp;将多个物体连接在一起以独特的方式进行交互。

## type

**类型：** 函数。

**描述：**

&emsp;&emsp;获取字符串形式的对象类型。

**签名：**
```tl
type: function(self: Joint): string
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string | 字符串类型。 |

## Of

**类型：** 函数。

**描述：**

&emsp;&emsp;检查对象是否属于某种类型。如果对象的层次结构中具有指定名称的类型，则此函数将返回 true。

**签名：**
```tl
typeOf: function(self: Joint, type_name: string): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| type_name | string | 要检查的类型的名称。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象属于指定类型，则为 true，否则为 false。 |

## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: Joint): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## destroy

**类型：** 函数。

**描述：**

&emsp;&emsp;明确摧毁关节。如果您在调用此函数后尝试使用该对象，将会发生错误。
在0.7.2中，当你没有时间等待垃圾回收时，这个函数
可用于立即释放对象。

**签名：**
```tl
destroy: function(self: Joint)
```

**描述：**

```tl

```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 关节是否被破坏。 |

## getAnchors

**类型：** 函数。

**描述：**

&emsp;&emsp;获取关节的锚点。

**签名：**
```tl
getAnchors: function(self: Joint): number, number, number, number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 主体 1 上锚点的 x 分量。 |
| number | 主体 1 上锚点的 y 分量。 |
| number | 主体 2 上锚点的 x 分量。 |
| number | 主体 2 上锚点的 y 分量。 |

## getReactionForce

**类型：** 函数。

**描述：**

&emsp;&emsp;返回第二个物体上的反作用力（以牛顿为单位）

**签名：**
```tl
getReactionForce: function(self: Joint, inverse_delta_time: number): number, number
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| inverse_delta_time | number | 力作用多长时间。通常为反时间步长或 1/dt。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 力的 x 分量。 |
| number | 力的 y 分量。 |

# Event

**描述：**

&emsp;&emsp;管理事件，例如按键。

## pump

**类型：** 函数。

**描述：**

&emsp;&emsp;Dora 拥有平台事件泵；这不会泵送第二个操作系统队列。将事件泵入事件队列。
这是一个低级函数，通常不由用户调用，而是由 love.run.
请注意，确实需要调用此命令才能让任何操作系统认为您仍在运行，
如果您想处理操作系统生成的事件（考虑回调）。

**签名：**
```tl
pump: function()
```

## poll

**类型：** 函数。

**描述：**

&emsp;&emsp;返回事件队列中消息的迭代器。

**签名：**
```tl
poll: function(): function(): any...
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| function or any... | 可在 for 循环中使用的迭代器函数。 |

## wait

**类型：** 函数。

**描述：**

&emsp;&emsp;与 love.event.poll() 类似，但会阻塞，直到队列中有事件为止。

**签名：**
```tl
wait: function(): any...
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| any... | 事件名称。 |

## push

**类型：** 函数。

**描述：**

&emsp;&emsp;将事件添加到事件队列。
从 0.10.0 开始，您可以使用此函数传递任意数量的参数，但默认回调不会使用超过六个。

**签名：**
```tl
push: function(name: string, args: any...): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| name | string | 事件的名称。 |
| args | any... | 第一个事件参数。 （默认值：无。） |

## clear

**类型：** 函数。

**描述：**

&emsp;&emsp;清除事件队列。

**签名：**
```tl
clear: function()
```

## quit

**类型：** 函数。

**描述：**

&emsp;&emsp;将退出事件添加到队列中。

	-- quit 事件是事件处理程序关闭 LÖVE 的信号。可以使用 love.quit 回调中止退出过程。

**签名：**
```tl
quit: function(exit_status?: number): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| exit_status | number | 关闭应用程序时使用的程序退出状态。 （默认值：0。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 退出事件加入队列后始终返回 true。 |

## quit

**类型：** 函数。

**描述：**

&emsp;&emsp;将退出事件添加到队列中。

	-- quit 事件是事件处理程序关闭 LÖVE 的信号。可以使用 love.quit 回调中止退出过程。

**签名：**
```tl
quit: function(reason: string): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| reason | string | 告诉默认的 love.run 退出并重新启动游戏，而不重新启动可执行文件。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 重启退出事件加入队列后始终返回 true。 |

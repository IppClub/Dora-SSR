## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: Joystick): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## getID

**类型：** 函数。

**描述：**

&emsp;&emsp;获取操纵杆的唯一标识符。即使操纵杆断开连接并重新连接，标识符在游戏的生命周期中也将保持不变，但当游戏重新启动时，它“'will'”会发生变化。

**签名：**
```tl
getID: function(self: Joystick): integer, integer | nil
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| integer | 操纵杆的唯一标识符。只要游戏运行，就保持不变。 |
| integer or nil | 唯一实例标识符。每次重新连接操纵杆时都会发生变化。如果操纵杆未连接则为零。 |

**签名：**
```tl

```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string | 操纵杆类型的依赖于操作系统的唯一标识符。 |

## getDeviceInfo

**类型：** 函数。

**描述：**

&emsp;&emsp;获取操纵杆的 USB 供应商 ID、产品 ID 和产品版本号，这些信息在不同操作系统中保持一致。
可用于为不同的游戏手柄显示不同的图标等。
重载说明：
1. 某些 Linux 发行版可能未附带 SDL 2.0.6 或更高版本，在这种情况下，此函数将为所有三个值返回 0。

**签名：**
```tl
getDeviceInfo: function(self: Joystick): integer, integer, integer
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| integer | 操纵杆的 USB 供应商 ID。 |
| integer | 操纵杆的 USB 产品 ID。 |
| integer | 操纵杆的产品版本。 |

## isDown

**类型：** 函数。

**描述：**

&emsp;&emsp;检查操纵杆上的按钮是否被按下。

**签名：**
```tl

```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| buttons | integer... | 要检查的按钮的索引。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果任何提供的按钮被按下，则为 True，否则为 false。 |

## isGamepad

**类型：** 函数。

**描述：**

&emsp;&emsp;获取Joystick是否被识别为游戏手柄。如果是这种情况，则可以通过 Joystick:getGamepadAxis、Joystick:isGamepadDown、love.gamepadpressed
和相关函数，在不同的操作系统和操纵杆型号中以标准化方式使用操纵杆的按钮和轴。
LÖVE 自动识别与 Xbox 360 控制器布局相似的最流行的控制器作为游戏手柄，但您可以使用 love.joystick.setGamepadMapping.
重载说明：
1. 如果操纵杆被识别为游戏手柄，则虚拟游戏手柄轴和按钮的物理位置尽可能与标准 Xbox 360 控制器的布局相对应。

**签名：**
```tl
isGamepad: function(self: Joystick): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果操纵杆被识别为游戏手柄则为 true，否则为 false。 |

## getGamepadMapping

**类型：** 函数。

**描述：**

&emsp;&emsp;获取虚拟游戏手柄输入绑定的按钮、轴或帽子。
重载说明：
1. 如果操纵杆未被识别为游戏手柄或虚拟游戏手柄轴未绑定到操纵杆输入，则返回 nil。 2. 虚拟游戏手柄轴和按钮的物理位置尽可能与标准 Xbox 360 控制器的布局相对应。

**签名：**
```tl
getGamepadMapping: function(self: Joystick, input: string): string | nil, integer | nil, string | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| input | string | 要获取绑定的虚拟游戏手柄轴。根据过载：要获取绑定的虚拟游戏手柄按钮。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string or nil | 虚拟游戏手柄轴绑定的输入类型。取决于过载：虚拟游戏手柄按钮绑定的输入类型。 |
| integer or nil | 虚拟游戏手柄轴绑定到的操纵杆按钮、轴或帽子的索引。 取决于过载：虚拟游戏手柄按钮绑定到的操纵杆按钮、轴或帽子的索引。 |
| string or nil | 帽子的方向（如果虚拟游戏手柄轴绑定到帽子）。否则为零。取决于过载：帽子的方向（如果虚拟游戏手柄按钮绑定到帽子）。否则为零。 |

## getGamepadMappingString

```tl
getGamepadMappingString: function(self: Joystick): string | nil
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string or nil | 包含操纵杆的游戏手柄映射的字符串，如果操纵杆未被识别为游戏手柄则为零。 |

| --- | --- |

## setVibration

**类型：** 函数。

**描述：**

&emsp;&emsp;设置带有震动支持的操纵杆上的振动电机速度。大多数常见的游戏手柄都具有此功能，但并非所有驱动程序都提供适当的支持。使用Joystick:isVibrationSupported进行检查。

**签名：**
```tl
setVibration: function(self: Joystick, left: number, right?: number, duration?: number): boolean
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| left | number | 操纵杆上左侧振动电机的强度。必须在 1 范围内。 |
| right | number | 操纵杆上右侧振动电机的强度。必须在 1 范围内。 |
| duration | number | 振动的持续时间（以秒为单位）。负值意味着无限的持续时间。 （默认值：-1。） |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果振动已成功禁用，则为 true；如果未成功禁用，则为 false。 |

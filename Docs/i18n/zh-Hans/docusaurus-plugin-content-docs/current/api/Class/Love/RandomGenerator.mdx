**返回值：**

| 返回类型 | 描述 |

## setSeed

**类型：** 函数。

**描述：**

&emsp;&emsp;使用指定的整数设置随机数生成器的种子。

**签名：**
```tl
setSeed: function(self: RandomGenerator, low: number, high: number)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| low | number | 种子值的低 32 位。必须在 2^32 - 1 范围内。 |
| high | number | 种子值的高 32 位。必须在 2^32 - 1 范围内。 |

## getSeed

**类型：** 函数。

**描述：**

&emsp;&emsp;获取随机数生成器对象的种子。
由于 Lua 对所有数值都使用双精度数，因此种子被分成两个数字 - 双精度数无法准确表示 2^53 以上的整数值，但种子值是 2^64 - 1 范围内的整数。

**签名：**
```tl
getSeed: function(self: RandomGenerator): number, number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 表示 RandomGenerator 的 64 位种子值的低 32 位的整数。 |
| number | 表示 RandomGenerator 的 64 位种子值的高 32 位的整数。 |

## setState

**类型：** 函数。

**描述：**

&emsp;&emsp;设置随机数生成器的当前状态。用作此函数参数的值是一个不透明字符串，并且只能源自 LÖVE 的同一主要版本中之前对 RandomGenerator:getState 的调用。
这与 RandomGenerator:setSeed 不同，setState 直接设置 RandomGenerator 的当前依赖于实现的状态，而 setSeed 为其提供新的种子值。
重载说明：
1. 状态字符串的效果与当前操作系统无关。

**签名：**
```tl
setState: function(self: RandomGenerator, state: string)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| state | string | RandomGenerator 对象的新状态，表示为字符串。这应该源自之前对 RandomGenerator:getState 的调用。 |

## getState

**类型：** 函数。

**描述：**

&emsp;&emsp;获取随机数生成器的当前状态。这会返回一个不透明的字符串，该字符串仅适用于以后与 LÖVE 的相同主要版本中的 RandomGenerator:setState 一起使用。
这与 RandomGenerator:getSeed 不同，getState 获取 RandomGenerator 的当前状态，而 getSeed 获取之前设置的种子数。
重载说明：
1. 状态字符串的值与当前操作系统无关。

**签名：**
```tl
getState: function(self: RandomGenerator): string
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| string | RandomGenerator 对象的当前状态，表示为字符串。 |

# Font

**描述：**

&emsp;&emsp;定义可以在屏幕上绘制的字符的形状。

## release

**类型：** 函数。

**描述：**

&emsp;&emsp;销毁对象的 Lua 引用。如果该对象未被任何其他 LÖVE 对象或线程引用，则该对象将被完全删除。
这个方法可以用来立即清理资源，而不需要等待Lua的垃圾收集器。

**签名：**
```tl
release: function(self: Font): boolean
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| boolean | 如果对象已通过此调用释放，则为 true；如果先前已释放过该对象，则为 false。 |

## getKerning

**类型：** 函数。

**描述：**

&emsp;&emsp;获取字体中两个字符之间的字距调整。
字距调整通常在 love.graphics.print、文本对象、Font:getWidth、Font:getWrap 等中自动处理。当手动将文本拼接在一起时，此功能非常有用。

**签名：**
```tl
getKerning: function(self: Font, left: string | integer, right: string | integer): number
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| left | string or integer | 左边的字符。取决于重载：左侧字形的 unicode 编号。 |
| right | string or integer | 正确的字符。取决于重载：正确字形的 unicode 编号。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 添加到两个字符之间的间距的字距调整量。可能是负值。 |

## setFallbacks

**类型：** 函数。

**描述：**

&emsp;&emsp;设置后备字体。当字体不包含字形时，它将替换下一个后续后备字体中的字形。这类似于在层叠样式表 (CSS) 中设置 'font stack'。
重载说明：
1. 如果调用此函数，则应在调用 love.graphics.print、Font:getWrap 和其他使用字形定位信息的 Font 方法之前调用。每个后备字体必须从与主字体相同的文件类型创建。例如，从 .ttf
文件创建的字体只能使用从 .ttf 文件创建的后备字体。

**签名：**
```tl
setFallbacks: function(self: Font, ...: Font)
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| ... | Font | ... 参数。 |

## getDPIScale

**类型：** 函数。

**描述：**

&emsp;&emsp;获取字体的 DPI 比例因子。
DPI 比例因子表示相对像素密度。 DPI 比例因子为 2 意味着与 DPI 比例因子为 1 的字体相比，字体的字形在每个维度上的像素密度是两倍（同一区域中像素数量的 4 倍）。
TrueType 字体的字体大小在内部按字体指定的 DPI 比例因子进行缩放。默认情况下，LÖVE 在创建 TrueType 字体时使用屏幕的 DPI 比例因子。

**签名：**
```tl
getDPIScale: function(self: Font): number
```

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 字体的 DPI 比例因子。 |

## getWrap

**类型：** 函数。

**描述：**

&emsp;&emsp;获取文本的格式信息（给定换行限制）。
此函数正确解释换行符（即 '\n'）。

**签名：**
```tl
getWrap: function(self: Font, text: string, wrap_limit: number): number, {string}
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| text | string | 将被换行的文本。 |
| wrap_limit | number | 在换行之前允许“'text'”每行的最大宽度（以像素为单位）。 |

**返回值：**

| 返回类型 | 描述 |
| --- | --- |
| number | 换行文本的最大宽度。 |
| \{string} | 包含换行的每一行文本的序列。 |

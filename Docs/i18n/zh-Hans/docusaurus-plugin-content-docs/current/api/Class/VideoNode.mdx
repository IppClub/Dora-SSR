# VideoNode

**描述：**

&emsp;&emsp;用于表示视频节点的类。

**类对象：**[VideoNode Class](/docs/api/Class%20Object/VideoNode)。

**继承自：**[Sprite](/docs/api/Class/Sprite)。

Web 版的 dora-preset 默认支持 Ogg/Theora 视频及内嵌 Vorbis 音轨；core 配置需要启用 VIDEO。视频解码在主循环执行，不要求 pthreads 或 SharedArrayBuffer。音频播放需要满足浏览器的用户操作解锁规则。

## pause

**类型：** 函数。

**描述：**

&emsp;&emsp;同时暂停视频和内嵌音轨。

**签名：**
```tl
pause: function(self: VideoNode)
```

## resume

**类型：** 函数。

**描述：**

&emsp;&emsp;同时恢复视频和内嵌音轨播放，已结束时从头播放。

**签名：**
```tl
resume: function(self: VideoNode)
```

## readonly

**类型：** 成员变量。

**描述：**

&emsp;&emsp;视频当前是否暂停。

**签名：**
```tl
readonly paused: boolean
```

## play

开始或继续音画播放；已结束时从头播放。

```tl
play: function(self: VideoNode)
```

## seek

以秒为单位同步跳转音画，限制在 [0, duration]。保持暂停状态，暂停画面会异步更新；忽略非有限数值。

```tl
seek: function(self: VideoNode, seconds: number)
```

## rewind

跳转到开头，保持暂停状态。

```tl
rewind: function(self: VideoNode)
```

## currentTime

当前播放位置，单位为秒。

```tl
readonly currentTime: number
```

## duration

总播放时长，单位为秒，取音画两条轨道中的较长时长。

```tl
readonly duration: number
```

## playing

节点在运行场景中请求播放且未暂停、未结束，包括缓冲过程。

```tl
readonly playing: boolean
```

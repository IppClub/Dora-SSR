## conf

**类型：** 函数。

**描述：**

&emsp;&emsp;如果您的游戏文件夹（或 .love 文件）中存在名为 conf.lua 的文件，则该文件会在加载 LÖVE 模块之前运行。您可以使用此文件覆盖 love.conf 函数，该函数稍后由 LÖVE 'boot' 脚本调用。使用
love.conf 函数，您可以设置一些配置选项，并更改窗口的默认大小、加载哪些模块等内容。

**签名：**
```tl
conf: function(config: Config) | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| config | Config | love.conf 函数采用一个参数：一张包含所有默认值的表，您可以根据自己的喜好覆盖这些默认值。例如，如果您想更改默认窗口大小，请执行以下操作： function love.conf(t) t.window.width = 1024 t.window.height = 768 end 如果您不需要物理模块或操纵杆模块，请执行以下操作。 function love.conf(t) t.modules.joystick = false t.modules.physicals = false end 当您发布游戏时，鼓励将未使用的模块设置为 false。它会稍微减少启动时间（特别是在禁用操纵杆模块的情况下）并减少内存使用量（稍微）。请注意，您无法禁用 love.filesystem；这是强制性的。爱情模块本身也是如此。 love.graphics 需要启用 love.window。 identity: 该标志确定游戏的保存目录的名称。请注意，您只能指定名称，而不能指定创建位置： t.identity = "gabe_HL3" -- 正确 t.identity = "c:/Users/gabe/HL3" -- 不正确 或者 love.filesystem.setIdentity 可用于在配置文件之外设置保存目录。 （默认值：无。） appendidentity: 该标志决定是否应先搜索游戏目录然后保存目录（true）或否则（false）（默认值：false。） version: t.version 应该是一个字符串，代表您的游戏所针对的 LÖVE 版本。它的格式应为 "X.Y.Z"，其中 X 是主要版本号，Y 是次要版本号，Z 是补丁级别。它允许 LÖVE 在不兼容时显示警告。它的默认值是运行的 LÖVE 版本。 （默认："11.5"。） console: 确定是否应在游戏窗口旁边打开控制台（仅限 Windows）。 注意：在 OSX 上，您可以通过终端运行 LÖVE 来获取控制台输出。 （默认值：假。） accelerometerjoystick: 设置 iOS 和 Android 上的设备加速计是否应显示为 3 轴操纵杆。不使用时禁用加速计可能会减少 CPU 使用率。 （默认值：true。） externalstorage: 设置文件是保存在 Android 上的外部存储（true）还是内部存储（false）中。 （默认值：假。） gammacorrect: 确定是否启用伽玛校正渲染（当系统支持时）。 （默认值：假。） audio: 音频选项。 audio.mic: 向用户请求麦克风权限。当用户允许时，love.audio.getRecordingDevices 将列出可用的录音设备。否则，love.audio.getRecordingDevices 返回空表，并在调用时显示一条消息以通知用户。 （默认值：假。） audio.mixwithsystem: 设置 LÖVE 打开时是否播放其他应用程序的背景音频/音乐。有关更多详细信息，请参阅 love.system.hasBackgroundMusic。 （默认值：true。） window: 可以推迟窗口创建，直到在代码中首次调用 love.window.setMode 。 为此，请在 love.conf 中设置 t.window = nil （或在旧版本中设置 t.screen = nil。）如果这样做，如果在代码中的第一个 love.window.setMode 之前调用 love.graphics 中的任何函数，LÖVE 可能会崩溃。 t.window 表在 0.9.0 之前的版本中被命名为 t.screen。 0.9.0 中的 love.conf 中不存在 t.screen 表，0.8.0 中的 love.conf 中不存在 t.window 表。这意味着如果不注意为正在使用的 LÖVE 版本使用正确的表，love.conf 将无法执行（因此它将回退到默认值）。 window.title: 设置游戏所在窗口的标题。或者可以使用 love.window.setTitle 在配置文件之外更改窗口标题。 （默认："Untitled"。） window.icon: 用作窗口图标的图像的文件路径。并非所有操作系统都支持非常大的图标图像。也可以使用 love.window.setIcon. 更改图标（默认值：nil。） window.width: 设置窗口的尺寸。如果这些标志设置为 0，LÖVE 会自动使用用户的桌面尺寸。 （默认值：800。） window.height: 设置窗口的尺寸。如果这些标志设置为 0，LÖVE 会自动使用用户的桌面尺寸。 （默认值：600。） window.borderless: 从窗口中删除所有边框视觉效果。请注意，不同操作系统的影响可能会有所不同。 （默认值：假。） window.resizable: 如果设置为 true，则允许用户调整游戏窗口的大小。 （默认值：假。） window.minwidth: 设置游戏窗口的最小宽度和高度（如果用户可以调整其大小）。如果您将 window.width 和 window.height 设置较低的值，LÖVE 将始终支持通过 window.minwidth 和 window.minheight 设置的最小尺寸。 （默认值：1。） window.minheight: 设置游戏窗口的最小宽度和高度（如果用户可以调整其大小）。如果您将 window.width 和 window.height 设置较低的值，LÖVE 将始终支持通过 window.minwidth 和 window.minheight 设置的最小尺寸。 （默认值：1。） window.fullscreen: 是否以全屏（true）或窗口（false）模式运行游戏。也可以通过 love.window.setFullscreen 或 love.window.setMode. 切换全屏（默认： false。） window.fullscreentype: 指定要使用的全屏模式类型（正常或桌面）。通常建议使用桌面，因为它在某些操作系统上比正常模式限制更少。 （默认："desktop"。） window.usedpiscale: 设置是否启用或禁用自动 DPI 缩放。 （默认值：true。） window.vsync: 启用或禁用垂直同步。垂直同步尝试使游戏保持稳定的帧速率，并可以防止屏幕撕裂等问题。如果您不知道关闭垂直同步可能产生的影响，建议保持垂直同步处于激活状态。在 LÖVE 11.0 之前，该值是布尔值（true 或 false）。从 LÖVE 11.0 开始，该值为数字（1 表示启用垂直同步，0 表示禁用垂直同步，-1 表示在支持时使用自适应垂直同步）。请注意，在 iOS 中，垂直同步始终处于启用状态且无法更改。 （默认值：true。） window.depth: 深度缓冲区中每个样本的位数（16/24/32，默认为 nil）（默认：nil。） window.stencil: 然后是深度缓冲区中每个样本的位数（一般为 8，默认为 nil）（默认：nil。） window.msaa: 用于多重采样抗锯齿的样本数。 （默认值：0。） window.display: 如果有多个监视器可用，则显示窗口的显示器索引。 （默认值：1。） window.highdpi: 请参阅 love.window.getPixelScale、love.window.toPixels 和 love.window.fromPixels. 如果您无法在具有 Retina 显示屏的 Mac 或 iOS 系统上测试游戏，建议禁用此选项，因为代码需要调整以确保内容看起来正确。 （默认值：假。） window.x: 确定窗口在用户屏幕上的位置。或者 love.window.setPosition 可用于动态更改位置。 （默认值：无。） window.y: 确定窗口在用户屏幕上的位置。或者 love.window.setPosition 可用于动态更改位置。 （默认值：无。） modules: 模块选项。 modules.audio: 启用音频模块。 （默认值：true。） modules.event: 启用事件模块。 （默认值：true。） modules.graphics: 启用图形模块。 （默认值：true。） modules.image: 启用图像模块。 （默认值：true。） modules.joystick: 启用摇杆模块。 （默认值：true。） modules.keyboard: 启用键盘模块。 （默认值：true。） modules.math: 启用数学模块。 （默认值：true。） modules.mouse: 启用鼠标模块。 （默认值：true。） modules.physics: 启用物理模块。 （默认值：true。） modules.sound: 启用声音模块。 （默认值：true。） modules.system: 启用系统模块。 （默认值：true。） modules.timer: 启用定时器模块。 （默认值：true。） modules.touch: 启用触摸模块。 （默认值：true。） modules.video: 启用视频模块。 （默认值：true。） modules.window: 启用窗口模块。 （默认值：true。） modules.thread: 启用线程模块。 （默认值：true。） 启用按键重复才能接收重复按键事件。这不会影响 love.textinput. 2。需要使用 love.keyboard.setKeyRepeat 启用按键重复才能接收重复按键事件。

**签名：**

## textinput

**类型：** 函数。

**描述：**

&emsp;&emsp;当用户输入文本时调用。例如，如果在美式键盘布局上按下 shift-2，将生成文本 '@'。
重载说明：
1. 虽然Lua字符串可以很好地存储UTF-8编码的unicode文本，但是Lua字符串库中的许多函数不会像您期望的那样处理文本。例如，#text（和
string.len(text)）将给出字符串中“'bytes'”的数量，而不是 unicode 字符的数量。 Lua wiki 和 Lua 创建者之一的演示给出了更深入的解释，并提供了一些技巧。 utf8 库可用于操作
UTF-8 编码的 unicode 文本（例如此函数中给出的 text 参数）。在 Android 和 iOS 上，默认情况下禁用 textinput；调用 love.keyboard.setTextInput 来启用它。

**签名：**
```tl
textinput: function(text: string) | nil
```

**参数：**

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| text | string | UTF-8 编码的 unicode 文本。 |

# GodotNode

**描述：**

&emsp;&emsp;以 [Sprite](/docs/api/Class/Sprite) 显示 Godot 项目画面。启动异步执行，操作项目前应检查 `running` 和 `lastError`。同一时间仅允许一个活动的 GodotNode。

**类对象：** [GodotNode 类](/docs/api/Class%20Object/GodotNode)。

## 字段

以下字段均为只读。

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| projectPath | string | 解析后的 Godot 项目目录或 `.pck` 路径。 |
| sceneFile | string | 请求的场景路径；空字符串表示项目主场景。 |
| lastError | string | 最近一次运行错误；未报告错误时为空。 |
| running | boolean | 是否已完成异步启动且节点处于活动状态。 |
| paused | boolean | 请求的场景暂停状态。 |
| unloaded | boolean | 项目是否已成功卸载。仅有 `running == false` 不代表卸载完成。 |
| viewportSize | Size | 当前输出分辨率，单位为像素；尺寸调整生效时更新。 |

继承的 `texture` 会随渲染更新，保留纹理引用并不会生成截图。自定义着色效果和混合模式需处理预乘透明度。

## unloadAsync

```tl
unloadAsync: function(self: GodotNode, callback: function(ok: boolean, error: string))
```

移除节点并异步卸载项目。回调在逻辑线程执行，`ok` 表示是否成功，`error` 提供失败原因。成功时 `unloaded` 变为 `true`，此后可创建新的 GodotNode 加载不同项目。创建下一个节点前必须等待此回调；卸载失败时不能切换项目。

项目卸载支持 macOS Metal、Linux EGL、Windows x64 WGL、Android EGL 和 WebGL2。不支持的运行库会通过回调返回 `false` 和原因。重复调用会异步收到同一结果。应用逻辑循环停止后，不保证继续派发回调。

## pause / resume

```tl
pause: function(self: GodotNode)
resume: function(self: GodotNode)
```

异步暂停或恢复 Godot SceneTree，也可在启动期间调用。暂停时仍继续渲染；处理模式为 `PROCESS_MODE_ALWAYS` 的 Godot 节点仍继续执行。

## restart

```tl
restart: function(self: GodotNode, sceneFile?: string): boolean
```

重新加载当前场景，或加载 `sceneFile` 指定的场景（例如 `"res://main.tscn"`）。省略路径或传入空字符串表示重载当前场景，autoload 会保留。

返回 `true` 表示请求已接受，异步错误通过 `lastError` 报告。此方法不用于切换项目。

## resizeViewport

```tl
resizeViewport: function(self: GodotNode, width: integer, height: integer): boolean
```

请求新的输出分辨率，每个维度为 1–8192 像素。返回 `true` 表示请求已接受，可检查 `viewportSize` 判断是否完成。尺寸无效、忙碌、尚未启动完成或不支持时返回 `false`，异步错误通过 `lastError` 报告。

操作保留场景、autoload、暂停状态和音频，但可能短暂停顿渲染。就绪节点的同尺寸请求直接成功，不重新分配纹理。保留的旧输出纹理引用会冻结为其最后一帧。显示缩放可通过 Sprite 变换独立控制，无需调整分辨率。支持的运行库也会随 Godot 根 Window 的尺寸变化更新输出分辨率。

## sendPointer / sendPointerMove

```tl
sendPointer: function(self: GodotNode, x: number, y: number, button: integer, pressed: boolean)
sendPointerMove: function(self: GodotNode, x: number, y: number)
```

转发指针按键或移动事件。坐标单位为输出像素，原点位于左上角，尚未应用 Dora Sprite 变换；Godot 会按内容缩放转换为场景坐标。`button` 使用 Godot 编号：1 为左键，2 为右键，3 为中键。每次按下（`pressed = true`）应配对释放（`false`）。节点的触摸和鼠标事件也会自动转发。

## sendKey / sendText

```tl
sendKey: function(self: GodotNode, name: string, pressed: boolean)
sendText: function(self: GodotNode, text: string)
```

`sendKey` 转发具名按键，例如 `"Space"`；每次按下应配对释放。`sendText` 转发已提交的 UTF-8 文本。宿主失焦时会释放已按下的鼠标和键盘状态。

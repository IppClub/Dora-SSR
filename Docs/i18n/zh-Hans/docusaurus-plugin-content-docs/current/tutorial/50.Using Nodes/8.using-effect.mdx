# 使用游戏特效系统

## 1. 引言

&emsp;&emsp;在游戏开发中，特效是提升游戏视觉体验的重要元素。它们可以增强游戏的氛围、突出关键事件，并提供即时的视觉反馈。本教程将介绍如何在 Dora SSR 引擎中使用 Effekseer 特效系统，以及如何使用引擎自带的 Particle 粒子系统。

制作 `.par` 粒子的操作步骤与截图见[粒子编辑器](#43-在-web-ide-中编辑粒子)。

## 2. 什么是 Effekseer？

&emsp;&emsp;[Effekseer](https://effekseer.github.io) 是一个免费、开源的特效编辑器，支持 Windows、macOS 和 Linux 等多个平台。它允许美术人员和开发者创建各种粒子效果，如爆炸、火焰、光束等。Effekseer 支持多种渲染模式和高级特性，如：

- **粒子发射与控制**：支持从点、线、面等多种形状发射粒子，并可对粒子的生命周期进行精细控制。
- **渲染特性**：支持混合模式、纹理贴图、光照和阴影等。
- **多平台支持**：可导出特效到多种游戏引擎和平台，包括 Dora SSR 等。

## 3. 使用 Effekseer

&emsp;&emsp;Dora SSR 引擎已经集成了 Effekseer 特效系统，开发者可以直接在游戏中加载和播放 Effekseer 编辑器生成的特效文件（通常以 `.efk` 或 `.efkefc` 为扩展名）。

### 3.1 EffekNode 类的使用

&emsp;&emsp;在 Dora SSR 中，可以使用 `EffekNode` 类来管理 Effekseer 特效的播放，并作为一个场景节点管理特效的几何位置、旋转和缩放等属性。以下是 `EffekNode` 类的主要方法和用法：

- **创建 EffekNode 对象**

	<TabItem value="lua" label="Lua">

	```lua
	local effekNode = EffekNode()
	```

	</TabItem>


	</TabItem>
	</Tabs>

- **播放特效**

	<Tabs groupId="language-select">
	<TabItem value="lua" label="Lua">

	```lua

	```

	</TabItem>
	<TabItem value="tl" label="Teal">

	</TabItem>

	</TabItem>

	- `filename`：特效文件的路径。
	- `pos`（可选）：播放特效的二维坐标，默认为 `(0, 0)`。
	- `z`（可选）：播放特效的 Z 轴坐标，默认为 `0`。

- **停止特效**

### 3.2 实战示例：播放一个激光特效

&emsp;&emsp;以下是一个完整的示例，展示如何在 Dora SSR 中播放一个名为 `Laser01.efk` 的激光特效，并在特效结束时进行回调处理。

<Tabs groupId="language-select">
<TabItem value="lua" label="Lua">

```lua
-- 引入必要的模块
local EffekNode <const> = require("EffekNode")
local Vec2 <const> = require("Vec2")

-- 创建 EffekNode 对象
local effekNode = EffekNode()

-- 设置特效节点整体的 3D 旋转角度
effekNode.angleY = -90

-- 在坐标 (100, 200) 处播放激光特效
local laserHandle = effekNode:play("Particle/effek/Laser01.efk", Vec2(100, 200))

-- 注册特效结束回调
effekNode:onEffekEnd(function(handle)
	if handle == laserHandle then
		print("激光特效已结束")
	end
end)
```

</TabItem>


### 3.4 多个特效的管理

&emsp;&emsp;如果需要同时播放多个特效，可以分别保存每个特效的句柄，并在回调中进行区分。

<Tabs groupId="language-select">
<TabItem value="lua" label="Lua">

```lua
-- 播放多个特效
local handle1 = effekNode:play("Explosion.efk", Vec2(150, 250))
local handle2 = effekNode:play("Sparkle.efk", Vec2(200, 300))

-- 回调处理
effekNode:onEffekEnd(function(handle)
	if handle == handle1 then
		print("爆炸特效已结束")
	elseif handle == handle2 then
		print("闪光特效已结束")
	end
end)
```

</TabItem>

## 4. 使用 Particle 类

&emsp;&emsp;在 Effekseer 集成之前，Dora SSR 提供了 `Particle` 类来处理 2D 粒子特效。

:::note 注意
然而，`Particle` 系统功能较为有限，主要依赖 CPU 进行计算，性能和效果都不如 Effekseer。因此，除非是只希望创建比较简单的粒子特效的场景，否则不推荐使用 `Particle` 类。
:::

### 4.3 在 Web IDE 中编辑粒子

[下载资源编辑器示例](@site/static/files/resource-editors-demo.zip)，上传并解压到工作空间，打开 `ResourceLab/fire.par`。示例保存的是“魔法”预设。自行创建时，右键点击项目文件夹，选择**新建 → Dora 粒子**。

1. 点击 `.par` 文件，进入粒子编辑器。
2. 在右侧选择**火焰**或**魔法**等预设作为起点。应用预设会修改粒子参数，保存后才会保留这些修改。
3. 在**通用**区域调整**发射率**、**最大数量**、**生命周期**和**生命周期变化**。例如，把发射率改为 `90`，比较预览中粒子的疏密。
4. 用**暂停 / 播放**观察运动，用**重新播放**从头预览。这些按钮控制编辑器内的预览。

<DocScreenshot src={particleImage} width={2400} height={1600} alt="粒子编辑器：预设、实时预览和常规参数" />

在右侧面板内向下滚动，可以找到更多参数：

- **颜色**与**尺寸 / 旋转**调整粒子生命周期中的颜色、淡出、大小和旋转。
- **纹理**指定图片，点击 **…** 浏览资源；留空时使用默认粒子纹理。使用自定义图片时，将它与项目一起保留。
- **发射器 → 重力 / 半径**选择运动模型，再调整速度、加速度或半径等参数，观察预览变化。

<DocScreenshot src={particleFieldsImage} width={660} height={1360} alt="粒子的纹理、混合方式和重力发射器参数" maxWidth={450} />

按 `Ctrl+S`（macOS 为 `⌘+S`）保存，等待标签页名称前的星号消失，再重新打开文件确认参数。`.par` 是 XML 资源，需要检查保存的数据时，可以使用**作为文本打开**。

运行所属项目，在引擎中核对效果。示例 `ResourceLab/init.lua` 使用以下代码：

```lua
local Dora = require("Dora")
local particle = Dora.Particle("fire.par")
particle.scaleX = 3
particle.scaleY = 3
particle:addTo(Dora.Director.entry)
particle:start()
```

<DocScreenshot src={particleRunImage} width={1200} height={850} alt="保存后的粒子资源正在 Dora 场景中运行" maxWidth={600} caption="入口脚本将这个特效放大 3 倍，方便观察运行效果。" />

修改资源后，先保存再重新运行项目。`.par` 由项目脚本加载，不能使用“运行文件”单独执行。

## 5. 总结

用 `EffekNode` 加载 Effekseer 制作的特效，用 `Particle` 加载 `.par` 粒子资源。制作 `.par` 时，可以直接使用 Web IDE 的粒子编辑器，保存后再放入游戏场景验证。

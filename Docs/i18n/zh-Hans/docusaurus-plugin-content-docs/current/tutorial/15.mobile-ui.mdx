# 移动界面与 Remix

用移动界面浏览本地作品，让 Dora Agent 修改项目，并在同一设备上试玩。Android/iOS 默认进入移动界面；Windows/macOS 默认打开内嵌 Web IDE；Linux 默认进入传统界面。安装和创建第一个项目的步骤见[快速开始](./10.quick-start.mdx)。

## 打开项目的 Remix

1. 在作品列表中选择**本地**，找到要修改的项目。
2. 点击 **Remix 作品**，或在作品卡片上向右滑，进入项目会话。
3. 新建项目时，选择 **+ 新建 → 新建作品**，填写名称，选择 **TypeScript**（默认）或 **Lua**，再点击**创建并进入 Remix**。
4. 尚未配置模型时，在配置面板中选择服务商模板并填写自己的 API Key。也可以先返回 Remix，稍后通过页首的**配置 AI**继续设置。

名称为空、含路径分隔符或与已有内容重名时，新建面板会保留，修改名称后重试即可。

## 选择计划或执行，再发送需求

- **计划**：讨论改动，确定实现思路。
- **执行**：让 Dora 实际修改项目。
- 输入需求后点击**发送**，也可以按 `Ctrl/Cmd+Enter`；单独按 Enter 为换行。
- 切换模式会保留草稿，不会发送请求。新会话默认使用执行模式；已有会话会记住模式，并与 Web IDE 共享。

<DocScreenshot src={planImage} width={860} height={1600} alt="Remix 中选中计划模式，旁边是执行，底部是尚未发送的草稿和发送按钮" maxWidth={360} caption="先选模式，再发送需求。图中草稿尚未发送。" />

不必先计划再执行。讨论完成后，需要 Dora 开始实现时，再自行切换为**执行**。任务运行、等待回答或收尾时，模式切换和发送暂不可用。

## 查看进度与停止任务

工作卡片和回复会显示在输入框上方。向上滚动可以阅读之前的内容；点击**有新内容 · 回到最新**可继续跟随最新进展。

Dora 工作时，**发送**会变为**停止**。点击停止后，等待任务停止完成，再发送新需求或离开 Remix；下一条需求的草稿会保留。执行任务完成后，可点击**立即试玩**。计划回复完成后，可以继续讨论，也可以切换到执行。

## 试玩与返回作品列表

1. 点击 Remix 页首的**返回**，或在会话区域向左滑，返回该项目的作品卡片。Agent 工作时先停止任务。
2. 点击**试玩**，或在本地作品卡片上向左滑。执行任务完成后，也可以直接在 Remix 中点击**立即试玩**。
3. 试玩时，点击游戏右侧边缘的小把手，展开**退出试玩**，再点击它即可停止试玩，返回作品列表。

<DocScreenshot src={playImage} width={860} height={1600} alt="本地游戏正在运行，右侧已展开退出试玩按钮" maxWidth={360} />

退出把手可以上下拖动。退出试玩或返回 Remix 的作品列表时，会恢复该项目的卡片和原来的页签。

## 切换界面

在传统首页选择**移动界面**；在移动作品列表左上角选择**切换传统界面**。设备会记住选择；切换不会改变工作空间或模型配置。移动界面会跟随窗口大小和设备方向调整布局。

Web IDE 连接期间会接管本地编辑与试玩。使用 Windows/macOS 内嵌 Web IDE 时，点击游戏左侧 **IDE** 标签返回编辑器；使用外部浏览器时，关闭所有 Web IDE 连接后，恢复本地作品列表或 Remix。更多文件和模型操作见 [Web IDE 常用操作](./18.web-ide.mdx)。

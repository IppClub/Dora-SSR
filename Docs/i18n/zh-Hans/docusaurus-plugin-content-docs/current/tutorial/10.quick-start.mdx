# 快速开始

## 1. Dora SSR 是什么？

![Dora SSR 项目示意图](@site/static/img/article/detail-zh.svg)

:::info 引擎简介
&emsp;&emsp;Dora SSR 是一个用于多种设备上快速开发游戏的游戏引擎。它内置易用的 Web IDE 开发工具链，支持在手机、开源掌机等设备上直接进行游戏开发。
:::

安装 Dora SSR，按你的设备选择上手方式，做出第一个交互场景。也可以先[在浏览器中试玩游戏](https://dora-ssr.net/zh-Hans/play)。

### 1. 安装并启动 {#desktop-install}

- **Windows**：安装 **Windows x64 MSI**，从开始菜单启动 Dora SSR。若显卡或驱动无法运行默认的 D3D12 版，可选择文件名带 `-opengl` 的包。
- **macOS**：解压 macOS 软件包并打开 Dora，或用 `brew install --cask ippclub/tap/dora-ssr` 安装。

Dora SSR 窗口会**自动打开内置 Web IDE**，直接在这里开始创建项目。

### 2. 新建项目，写入代码 {#desktop-step-2}

1. 在内置 Web IDE 的左侧资源树中，右键点击「工作空间」（触屏可长按），选择「新建 → 文件夹」。
2. 输入 `Hello`，勾选「创建为项目」，保留默认的 **TypeScript** 类型，点击「确定」。
3. 展开 `Hello`，打开 `init.ts`，用下方代码替换文件内容。它会显示一张图片，并让图片移动到点击或触摸的位置。

<TabItem value="tsx" label="TSX">

```tsx title="Hello/init.tsx"
// @preview-file on
import {React, toNode, toAction, useRef} from 'DoraX';
import {Ease, Sprite, Touch} from 'Dora';

const sprite = useRef<Sprite.Type>();
const onTapBegan = (touch: Touch.Type) => {
	const {current} = sprite;
	if (current) {
		const {x, y} = touch.location;
		current.perform(toAction(
			<move time={1}
				startX={current.x} startY={current.y}
				stopX={x} stopY={y}
				easing={Ease.OutBack}
			/>
		));
	}
};
toNode(
	<node onTapBegan={onTapBegan}>
		<sprite ref={sprite} file='Image/logo.png'/>
	</node>
);
```

<TabItem value="wa" label="Wa">

使用 Wa 时，通过「新建 → Wa」并勾选「创建为 Wa 项目」来创建 `Hello`，再编辑 `src/main.wa`。

```go title="Hello/src/main.wa"
import "dora"

func init {
	sprite := dora.NewSpriteWithFile("Image/logo.png")
	root := dora.NewNode()
	root.AddChild(sprite.Node)
	root.OnTapBegan(func(touch: dora.Touch) {
		sprite.PerformDef(dora.ActionDefMoveTo(
			1.0,                  // 持续时间，单位为秒
			sprite.GetPosition(), // 开始位置
			touch.GetLocation(),  // 结束位置
			dora.EaseOutBack,     // 缓动函数
		), false)
	})
}
```

### 3. 运行看看 {#desktop-step-3}

按 **Ctrl + S** 保存，再点击三角形「运行」按钮（或按 **Ctrl + R**）。macOS 将 Ctrl 换为 **⌘**。

**Windows/macOS**：运行成功后，同一个 Dora SSR 窗口会从内置 IDE 切换到游戏画面。点击或触摸可移动图片；点击左侧的 **IDE** 页签返回编辑，再点击「停止」结束运行。

</a>

### 4. 分享作品 {#desktop-step-4}

右键点击 `Hello` 文件夹，选择「导出 → 导出 HTML」。完整解压下载的 ZIP，再在浏览器中打开根目录的 `index.html`，即可试玩；保留所有配套文件。要备份项目或分享给他人继续编辑，选择「导出 ZIP 包」。

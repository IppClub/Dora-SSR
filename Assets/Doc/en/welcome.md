# Welcome to Dora SSR!

![logo:250](../image/dora-toto.png)

&emsp;&emsp;Congratulations on discovering this treasure! Dora SSR is software dedicated to fast game development on a variety of devices. The game development toolkit is included, requiring only a device running the engine (such as a smartphone, open-source gaming handheld, or desktop) and any coding device (such as a PC or tablet). With the software and a browser open, you can start making games immediately.

## Key Features

&emsp;&emsp;The Dora SSR engine offers a rich set of features, including:

- Built-in out-of-the-box Web IDE, providing file management, code inspection, completion, highlighting, and jump-to-definition.
- Built-in Coding Agent brings LLM-assisted development into the game engine with project skills, persistent memory, file search, Dora API lookup, safe file edits, build checks, runtime validation, and sub-agent delegation.
- Manages tree-based [2D and 3D game scenes](https://dora-ssr.net/docs/tutorial/setup-scene), with cameras, materials, lighting, models, animation, and 3D physics.
- Basic [2D platformer](https://dora-ssr.net/docs/example/Platformer%20Tutorial/start) game functions, including game logic and an AI development framework.
- Easy-to-use [ECS](https://dora-ssr.net/docs/tutorial/using-ecs) module for game entity management.
- [Asynchronous processing](https://dora-ssr.net/docs/tutorial/using-update#example-executing-a-global-coroutine-task) for file access, resource loading, and other operations.
- Upgraded Lua bindings with support for inheriting from and extending low-level C++ objects.
- Supports [YueScript](https://dora-ssr.net/docs/tutorial/Language%20Tutorial/yuescript-15min), a concise and expressive Lua dialect.
- Supports [Teal](https://dora-ssr.net/docs/tutorial/Language%20Tutorial/teal-tutorial), a statically typed language that compiles to Lua.
- Supports [TypeScript](https://dora-ssr.net/docs/tutorial/Language%20Tutorial/Using%20TypeScript%20in%20Dora/try-tstl), a statically typed superset of JavaScript with powerful type checking.
- Supports [TSX](https://dora-ssr.net/docs/tutorial/Language%20Tutorial/using-tsx), allowing XML/HTML-like text to be embedded in TypeScript.
- Supports [Wa](https://wa-lang.org), a simple, reliable, statically typed language running on the built-in WASM runtime with [Wa bindings](https://github.com/IppClub/Dora-SSR/tree/main/Tools/dora-wa).
- Supports [Rust](https://dora-ssr.net/blog/2024/4/15/rusty-game-dev), running on the built-in WASM runtime with Rust bindings.
- Supports C# for extending and integrating the engine through native dynamic-library interfaces.
- Includes a Scratch-like Blockly visual programming environment for teaching, prototyping, and beginner-friendly onboarding.
- Supports 2D [skeletal animation](https://dora-ssr.net/docs/tutorial/Using%20Nodes/using-playable) and a [physics engine](https://dora-ssr.net/docs/tutorial/Using%20Nodes/using-physics-1).
- Built-in Animation Editor for creating and editing 2D model animation resources with visual tree editing, keyframes, clips, playback, and transform tools.
- The Web IDE also includes particle, physics, visual-script, Yarn, Spine, tile-map, Git, profiler, and TIC-80 editors.
- Runs natively on Android, Windows, Linux, macOS, and iOS, with a [HarmonyOS port](https://github.com/IppClub/ohos_dora_ssr).
- Supports H.264 / AVC Annex-B `.h264` video playback.
- Supports asynchronous [SQLite](https://dora-ssr.net/docs/tutorial/Managing%20Game%20Data/using-database) operations for real-time queries and managing large game configuration datasets.
- Supports reading [Excel](https://dora-ssr.net/docs/tutorial/Managing%20Game%20Data/using-excel) spreadsheet data and synchronizing it to SQLite tables.
- Provides adaptive [Flex layout](https://dora-ssr.net/docs/tutorial/adapting-to-screen#32-using-css-flex-layout) for game scenes through CSS.
- Supports the [Effekseer](https://dora-ssr.net/docs/tutorial/Using%20Nodes/using-effect) game effects system.
- Supports parsing and rendering TMX map files created with [Tiled Map Editor](https://dora-ssr.net/docs/tutorial/Using%20Nodes/using-tilemap).
- Built-in [machine learning](https://dora-ssr.net/docs/tutorial/Using%20Machine%20Learning/using-decision-tree) algorithm framework for innovative gameplay.
- Supports [Yarn Spinner](https://dora-ssr.net/docs/tutorial/Writing%20Game%20Dialogue/introduction-to-yarn), making it easy to write complex game story systems.
- Provides a [vector graphics](https://dora-ssr.net/docs/tutorial/Using%20Nodes/using-vg-node) rendering API that can directly render SVG files without CSS.
- Built-in [ImGui](https://dora-ssr.net/docs/tutorial/using-imgui) for creating debugging tools and UI.
- Supports bgfx-style cross-platform graphics shader runtime compilation.
- Supports FLAC, OGG, MP3, and WAV audio playback with 3D spatial sound, distance attenuation, and Doppler effects.
- Supports TrueType font rendering and basic typesetting with SDF support.
- Provides open art resources and game IP that can be used to create your own games — ["Luv Sense Digital"](https://luv-sense-digital.readthedocs.io).

# 模型密钥存储

> 2026-09-19：当前实现已迁移至 Go 的 `internal/studio`；本文中的 `.mjs` 模块名是迁移前的设计来源，不是现行部署入口。

model-secret-vault.mjs 是可信后端内部存储，不是身份系统或公开 API。共享密钥固定属于 platform；BYOK 绑定账号与配置。调用方必须先完成管理员/账号授权及用户托管 Key 的明确同意。

- 使用 AES-256-GCM、每次随机 12 字节 nonce，将用途版本、资金来源、所属账号、配置、记录版本和主密钥 ID 作为认证附加数据。数据库只保存密文、认证标签和非秘密元数据。
- 主密钥由部署密钥管理提供 32 字节字节串，不写入数据库。启动配置支持多版本读取及一个当前写入版本；轮换需逐记录以原版本检查重写，所有仍需读取的旧密文及备份迁移完成前不得删除旧主密钥。
- put/revoke 与无秘密内容的审计在同一事务；旧版本拒绝覆盖。metadata 仅返回版本和可用状态，不能把读取元数据作为授权。
- withSecret 仅允许可信供应商请求模块使用，回调结束清零其临时 Buffer；JS/HTTP 库自行复制的字符串或内存不受此清零保证。禁止把解密内容传给 Agent、项目代码、日志或 API 响应。
- revoke 写入版本化不可用状态，不是物理擦除；已有在途调用、进程中的副本、WAL 和历史备份不能通过撤销立即消除。正式服务仍需停止新派发、管理备份访问和供应商端密钥撤销。

真实临时 SQLite 测试验证存储重开、跨账号移植/密文篡改失败、版本冲突、审计失败回滚、主密钥轮换与撤销。测试仅用随机主密钥和明确的假 API Key。尚未接正式密钥管理服务、配置后台、BYOK 设置及网关，未进行安全审计/生产部署验收。

## BYOK HTTP 边界

model-byok-secret-route.mjs 提供 GET/PUT/DELETE /api/byok/configurations/:id/secret。配置归属通过注入的可信授权器取得；写入要求同源 Origin、JSON、版本前置条件和 consent:true，不接受客户端 ownerId/资金来源/服务地址。上传上限 64 KiB，Key 上限 16 KiB，并拒绝控制字符；读取上传后再次授权。响应只含 version/available，冲突 409，不回传 Key 或内部异常。

该路由尚未挂载正式服务，授权测试使用 fixture。正式配置所有权撤销需与写入事务协调，服务端还须设置请求超时、速率限制、HTTPS 与真实会话认证；不能仅凭回调存在宣称身份系统完成。字节缓冲尽力清零不保证 JSON 字符串或运行时副本物理擦除。

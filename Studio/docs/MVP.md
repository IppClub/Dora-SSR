# Dora Studio 受邀预览 MVP

更新日期：2026-09-16。目标版本：`studio-mvp-preview`。

**状态：代理用户整链验收已通过，可进入小规模受邀技术预览。** 这不等于完整首版、公开发布、生产部署或真人 Beta 签收完成。

## 目标

在接下来几轮开发工作中，交付一个可以部署并由小规模受邀用户试用的核心闭环：

> 管理员配置一个真实共享模型；创作者登录后输入一句描述，原 Dora Agent 自主修改、构建并试玩游戏；创作者可以持续继续描述修改，不设产品轮次上限；刷新或一次可恢复故障后仍能继续，金额和项目状态保持正确。

MVP 通过表示可以进入受邀 Beta，不表示完整首版、公开发布或完整 Agent 等价验收已经完成。

## MVP 范围

必须交付：

1. 邀请码＋账号密码登录，管理员与创作者权限分离。
2. 管理员配置一种真实 HTTPS 兼容共享模型、人民币费率和账号额度。
3. 首页一句描述创建独立项目并启动绑定的原 Dora Agent 会话。
4. 真实模型自行选择原 Agent 工具，生成一个有可观察画面的轻量 2D 游戏。
5. 原 Agent 通过既有 `build`、命令/`previewGame` 工具触发构建和试玩；Studio 不增加任务后处理。
6. 创作者可以在同一项目持续继续描述；每轮独立关联修改、检查点、试玩反馈和金额记录。
7. 项目、Agent 会话、检查点、模型请求和金额记录在刷新后保持一致。
8. 至少一次可恢复失败不会重复创建项目、应用修改、请求模型或结算金额。
9. 正式前端、API、Agent Host 和独立 Player 可在一个可重复启动的 HTTPS 环境运行。

本轮不作为 MVP 门槛：

- BYOK 实际派发；现有设置和用量界面保留。
- 完整 Agent 逐工具/模式/子任务/压缩/音乐音效对照。
- 公开发布、源码开放、Remix 和外部开源链接 clone。
- Firefox、Safari、真实手机和完整无障碍/性能矩阵。
- 多供应商、自动队列调度、多实例、生产对象存储及灾难恢复。
- 真实受邀用户签收；先由 Agent 使用隔离测试账号完成可重复验收，随后进入 Beta。

这些能力仍属于完整首版，不因 MVP 延后而取消。

## 开发轮次

### 第 1 轮：真实模型与入口收口

- 完成 #71：由管理员配置的一个真实共享模型走通原 Agent 请求和 usage 结算。
- 完成 #72：校准未就绪、启动中、运行中、可重试失败和确认不明状态。
- 删除“试玩尚未接入”等与当前能力不符的文案。

出口证据：正式前端、API 和 Agent Host 同时运行，真实模型至少成功响应一次；供应商拒绝、余额不足和配置撤销能明确失败。

### 第 2 轮：首轮生成（已完成）

- 完成真实模型首轮路径。
- 使用真实模型从描述生成轻量 2D 游戏。
- 保存作者 revision、检查点、Agent 工具活动、构建结果和 Player 画面。

出口证据：不是固定模型回复；原 Agent 自行调用工具；独立 Player 显示非空游戏画面；回写后没有 Studio 追加自动编译或常驻试玩。

### 第 3 轮：持续修改与恢复

- 在同一项目连续提交至少两次继续描述，观察每轮源码、revision、金额和画面变化。
- 注入一次可恢复的云上传、模型或宿主失败，再刷新续接。
- 核对不会重复创建项目、重复修改、重复请求或重复结算。

出口证据：首轮和后续各轮结果可观察区分；恢复后保持同一项目和会话；账本与模型请求一一对应。两次继续描述只是最小验收样本，不是产品轮次上限。

### 第 4 轮：MVP 整体验收（已完成）

- 用全新管理员、创作者和隔离数据库执行完整流程。
- 检查另一个账号不能读取该项目。
- 固化启动步骤、测试证据、已知限制和 Beta 结论。

出口证据：一份可复现验收记录，包含浏览器、引擎 build、模型配置、项目 revision、人民币用量、首轮及连续修改画面与失败恢复结果。

## 验收清单

- [x] 管理员能导入并启用真实共享模型，Key 不返回浏览器。
- [x] 创作者能注册、登录、看到可用人民币额度并选择模型。
- [x] 一句描述只创建一个独立项目和一个绑定会话。
- [x] 真实模型自主完成首轮编辑、构建和试玩。
- [x] 独立 Player 显示可识别的游戏画面，工具日志和截图可追溯。
- [x] 连续两次继续描述都修改同一项目，revision、检查点和画面逐轮发生预期变化。
- [x] 首轮及后续各轮模型调用分别产生正确的预留、结算和余额变化。
- [x] 刷新后项目、会话、描述状态和用量可恢复。
- [x] 一次注入失败可重试，且没有重复项目、修改、请求或结算。
- [x] 第二个账号不能读取项目、Agent Host 私有资源或模型配置。
- [x] 前端、API、Agent Host、Player 全部通过 HTTPS 启动，测试结束可完整关闭。
- [x] `cd Studio && pnpm test` 通过，MVP 浏览器整链另行通过。

任一项未通过，MVP 保持未完成；局部单测、固定模型桩或静态构建不能替代整链。

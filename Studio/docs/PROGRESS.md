# Dora Studio 开发进度

更新日期：2026-09-18。

## 当前结论

**Dora Studio 受邀预览 MVP 的代理用户整链已经通过，可进入小规模技术预览；完整首版仍未通过验收。**

真实 DeepSeek 已在隔离 HTTPS 环境完成首轮生成、两次同项目继续描述、逐轮 Player 截图、刷新/503 恢复、人民币结算和跨账号源码隔离。产品不限制继续修改轮次。下一阶段转向真人受邀试用和完整首版：完整 Agent 对照、BYOK 派发、发布/分享/Remix、外部 clone、设备矩阵与生产运维。

最新验证：

- `cd Studio && pnpm test`：构建成功，391/391 单测通过；此命令不包含浏览器脚本。
- 五服务 HTTPS Chrome：邀请码注册、共享授权、人民币 usage 结算、原 Agent 编辑 XML/入口、原 `build` 和原 `previewGame` 独立 Player 截图通过。
- 截图为 740×340，绿色游戏区域超过 10,000 像素并经人工查看。
- 作者回写后仍显示“尚未编译”，Studio 没有追加自动编译或常驻试玩。
- 一句描述入口的未就绪、启动、可恢复失败、确认不明和已启动状态已收口；云 PUT 503 后刷新恢复同一项目、切换项目不重投通过。
- 正式界面的零余额、配置停用和供应商拒绝均失败关闭；拒绝请求保持 `in-flight`，恢复配置后重新可用。
- Agent 侧栏已支持不限轮次的继续描述；固定模型桩连续完成 r1→蓝色 r2→刷新/503 恢复→黄色 r3，逐轮 checkpoint、试玩 PNG 和金额增量通过。

## 固定行为边界

- 构建和试玩只由原 Agent 的 `build`、`execute_command`/`previewGame` 等工具或用户手动操作触发。
- Studio 在任务终态和作者回写时只核对、保存文件，不附加自动编译或运行。
- 游戏运行渲染在浏览器 Player；账号、密钥、金额、授权和发布由可信后端处理。
- 源码默认私有；公开试玩不等于开放源码，Remix 必须由作者人工允许。
- 自动化、模拟视口和固定模型桩不能替代真实供应商、真实设备或真人验收。
- 产品界面不管理或展示项目版本号；项目、历史与远端判断使用更新时间。内部修订号和请求标识仅用于并发、幂等及迟到结果隔离。
- 前端工作区是作者内容的权威来源，保存和 Agent 回写后自动同步；只有失败时显示重试，只有远端更新时间较新时询问是否覆盖本机。
- 已有 Agent 项目在登录并打开后自动连接和同步；正常界面不再显示“连接项目 Agent”，仅在自动连接失败后提供重试。
- Agent 连接后输入框持续可用，不再等待首轮/上一轮回写、任务终态或人工保存；未保存编辑会在发送前自动保存并同步，每条新描述按独立请求投递，后台回写不阻塞继续创作。

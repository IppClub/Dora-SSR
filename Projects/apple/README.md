# Generated Apple projects

The macOS and iOS Xcode projects are generated by CMake. Edit `AppleApp.cmake`
and the platform `CMakeLists.txt` files rather than editing `project.pbxproj`.
The portable C++ source list comes from `Projects/CMake/DoraEngineSources.cmake`.

The build scripts create the required SDL2, bgfx, LOVE, theora, Wa and Rust
libraries before generating the app project:

```sh
Tools/build-scripts/build_macos.sh debug
Tools/build-scripts/build_ios.sh debug
```

For inspection or an IDE build, after building those libraries:

```sh
cmake -S Projects/macOS -B Projects/macOS/build-cmake -G Xcode
open Projects/macOS/build-cmake/Dora.xcodeproj

cmake -S Projects/iOS -B Projects/iOS/build-cmake-simulator -G Xcode \
  -DCMAKE_SYSTEM_NAME=iOS -DCMAKE_OSX_SYSROOT=iphonesimulator \
  -DCMAKE_OSX_ARCHITECTURES=arm64 -DDORA_IOS_VARIANT=simulator
open Projects/iOS/build-cmake-simulator/Dora.xcodeproj
```

An iOS device project needs device libraries and a separate build directory:

```sh
cmake -S Projects/iOS -B Projects/iOS/build-cmake-device -G Xcode \
  -DCMAKE_SYSTEM_NAME=iOS -DCMAKE_OSX_SYSROOT=iphoneos \
  -DCMAKE_OSX_ARCHITECTURES=arm64 -DDORA_IOS_VARIANT=device
```

The project includes resources that exist at configure time. Reconfigure after
generating `Assets/www` or `Assets/dora-wa` for a release package.
